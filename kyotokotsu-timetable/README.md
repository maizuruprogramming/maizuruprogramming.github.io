# 京都交通 高速バス時刻表ガイド（非公式）

京都交通公式サイトに掲載されている舞鶴発着の高速バス4路線を、スマートフォンでも確認しやすい形に整理した静的Webサイトです。

## 収録路線

- 舞鶴～大阪梅田
- 舞鶴～大阪なんば・伊丹空港
- 舞鶴～神戸三宮・神戸空港
- 舞鶴～京都駅

## 起動方法

`index.html` をブラウザで開いてください。サーバーやビルド作業は不要です。

Webサーバーに設置する場合は、このフォルダー内の `index.html`、`style.css`、`app.js` を同じディレクトリに配置してください。 `index.html` は `./app.js` と `./style.css` を読み込みます。3ファイルの名前を変更せず、必ずセットでアップロードしてください。

## 操作

1. 行き先の路線を選択
2. 「○○行き」または「舞鶴行き」を選択
3. 乗車する停留所を選択
4. 表示された便カードを開くと、全停留所の時刻を確認できます
5. 便番号・停留所名などで絞り込み検索できます
6. 神戸線は「神戸三宮」を初期選択し、予約案内は日本交通の公式ページへリンクします

## データについて

時刻データは2026年11月22日に京都交通公式サイトで確認した掲載内容を整理したものです。改正日は路線ごとに異なります。運休・臨時便・最新の変更を自動取得する仕組みはありません。実際の乗車・予約前には必ず公式サイトをご確認ください。
