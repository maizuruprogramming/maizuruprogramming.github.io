## 1. 目的と背景

### 1.1 目的
- 小・中学生が、ブロックを組み合わせるだけでプログラミングの基本（順次・反復・条件分岐・変数・アルゴリズムの一般化）を楽しく学べる教材を作る。
- HTML だけで動き、GitHub で公開・配布できる形にする。インストールやビルドは不要とする。
- 授業、科学イベント（例：「青少年のための科学の祭典」）、家庭学習で使えるようにする。
- 解説書・解説動画・解答集・修了証をそろえ、先生や保護者が準備や説明に使えるようにする。

### 1.2 方針
- ブロックエディタには Google の **Blockly**（Apache License 2.0）を使う。
- 見た目はマインクラフト風のドット絵とする。ただし、既存作品のキャラクター・テクスチャ・ロゴ・名称は使わず、オリジナルのデザインで雰囲気を寄せる。
- 「みんなの作品が1つの画面で泳ぐ」体験（Viscuit の水族館のような体験）を、名称や画面デザインはまねせずに、オリジナルの形で実現する。

## 2. 対象利用者と利用場面

| 利用者 | 主な使い方 |
|---|---|
| 小学生（低〜高学年） | ひらがな中心の画面で、迷路・おえかきを解く |

想定端末：PC（Chrome / Edge / Safari）、iPad（横 1024〜1366px、縦 744〜1024px）、電子黒板・プロジェクター。

## 4. 共通要件（全ページ）

### 4.1 画面構成
- 左にブロックを組む場所（Blockly）、右に課題パネル・盤面・メッセージを置く。
- 幅 900px 以下では、ブロックの場所（画面の高さの 60%）と盤面を縦に並べる。
- ヘッダーには、タイトル、他ページへのリンク（🐢 ⛏ 🚀 🧱 🐟 のうち自分以外。🎬 どうが・📖 かいせつしょ は「⚙ きのう」から開く）、▶ じっこう、↺ もどす、📖 こたえ（先生モードのみ）、⚙ きのう を置く。
- 支援ページ（どうが・かいせつしょ）のヘッダーは、タイトル、他ページへのリンク、⚙ きのう とする。

### 4.2 デザインの統一
- ヘッダー（高さ 56px）、ボタン、パネル（幅 400px）、右列（幅 440px）、盤面の枠（400×400px＋黒枠）、メッセージ、クリアのウィンドウの形と大きさは `common.css` で全アプリ共通とする。
- 各ページは CSS 変数（`--hdr-bg` `--panel-bg` など）でテーマの色だけを決める。

| アプリ | テーマ |
|---|---|
| おえかき | 空とノート |
| めいろ | 草と土 |
| うちゅう | 宇宙 |
| こわす・おく | 石と洞くつ |
| すいぞくかん | 海 |
| かいせつ どうが | えいがかん |
| かいせつしょ | ほんだな |

- 「▶ じっこう」ボタンは全アプリ同じ緑とする。
- 文字はドットフォント（DotGothic16）に統一する。子ども向けの表示はひらがな中心とする。

### 4.3 ヘッダーの1行表示（iPad 対応）
画面幅に応じて段階的に文字を隠し、ヘッダーを常に1行に収める。

| 画面幅 | 表示 |
|---|---|
| 1441px 以上 | すべて文字付き |
| 1440px 以下 | アプリのリンクはアイコンだけ |
| 1240px 以下 | 「▶ じっこう」「⚙ きのう」以外のボタンはアイコンだけ |
| 860px 以下 | タイトルと「⚙ きのう」もアイコンだけ |

- 受け入れ基準：全ページ × 2言語 × 14通りの幅（744〜1920px）で、ヘッダーのボタン・リンクが2行にならないこと。

### 4.3.1 📱 スマホの配置（幅 600px 以下、mobile.css／mobile.js）
画面の幅が 600px 以下のときだけ、スマホ向けの配置に切り替える。601px 以上（PC・iPad）の見た目と操作は変えない。画面を回したり幅を変えたりしたときは、その場で切り替わる。

- 対象：🐢 おえかき・⛏ めいろ・🚀 うちゅう・🧱 こわす・おく と、Python版4つ（すいぞくかん は対象外）。
- 並び：上から ステージ（もんだい）→ 盤面（画面の幅に合わせて縮める）→ プログラム。画面のいちばん下に、ブロックの棚と「▶ じっこう」「もどす（けす）」を固定する。
- ブロックの組み立ては、ドラッグではなく「タップで足す」。
  - 棚のブロックをタップすると、選んでいる場所（はじめはプログラムのさいご）に付く。
  - 「くりかえす」「もし」など中に入れられるブロックを足すと、次からはその中に入る。「＋ ここに いれる／つける」をタップして場所を変えられる。
  - ▲で一つ上へ、×で消す（後ろのブロックはつながったまま）。「ぜんぶ けす」は確認してから消す。
  - かずは入力欄、えらぶもの（向き・色など）はリストで直す。かずの入力欄は、タップすると数字のキーボードが出る。数字を打ち、欄の外をタップするか「完了」「改行」を押すと決まる（空のまま、または数字でないときは元の数字に戻す）。文字が小さいと iPhone で画面が拡大されるため、入力欄の文字は 16px 以上とする。かず・へんすうのブロックがあるアプリでは、◇をタップして入れる場所を選ぶ。分類のあるアプリ（おえかき）は棚の上に分類のボタンを出す。
  - 実行中のブロックは黄色く光る。「▶ じっこう」を押すと盤面が見える位置まで戻る。
- 裏では今までどおり Blockly のワークスペースを使う。保存・ブロック数・こたえあわせ・修了証は PC と同じで、PC とスマホで続きから遊べる。
- Python版：ブロック タブは上と同じタップ入力。Python タブでは命令ボタンに「→| さげる」「|← あげる」（字下げ）を加え、対応表は隠す。
- ⚙ きのう メニューは画面の下から出す。
- 実装上の注意：Blockly 10 以降では、かずの欄（FieldNumber）は FieldTextInput の仲間ではなく FieldInput の仲間である。入力欄にするかどうかは FieldNumber・FieldInput・FieldTextInput のいずれかで判定する（1.15 の初版では FieldTextInput だけで判定したため、実機でかずが文字として表示され、変えられなかった）。
- 受け入れ基準：幅 390px と 440px（iPhone 17 Pro Max 相当）で各アプリのステージを、タップだけで組んでクリアできること。ブロックの中のかずを入力欄で変えられ、保存に反映されること。幅を 600px より広げると PC の配置に戻り、ボタンもヘッダーに戻ること。

### 4.5 日本語／英語の切り替え
- 画面の文字、ブロックの文字、ステージ・おだいの説明とヒント、メッセージ、ダイアログ、修了証を切り替える。
- Blockly 標準の文言（右クリックメニュー等）も、対応する言語ファイルを読み込んで切り替える（Blockly を使わない支援ページでは読み込まない）。
- 解説動画は言語に合わせて日本語版／英語版を、解説書は日本語／英語の文と解答画像を出し分ける。
- 標準ブロックの表示は日本語ではひらがなに固定する（例：「4 かい くりかえす」「i を 1 から 10 まで 1 ずつ かぞえる」）。
- 選んだ言語は端末に記憶し、全アプリで共通とする。URL の `?lang=en`／`?lang=ja` でも指定できる。
- 切り替えても、組んだブロックと進み具合は消えない。
- 英語は小学生にも読めるやさしい表現とする。

### 4.6 ナイトモード・落ち着いた色・フォント
- ナイトモード：背景・パネル・ボタン・メニューを暗い色にし、盤面と絵は明るさを約 78% に下げる。暗くしても、おえかきのお手本の線と描いた線が見えること。
- 落ち着いた色：画面全体の彩度を 45%、コントラストを 90% にする。テーマの雰囲気は残す。
- 2つは同時に使える。設定は端末に記憶し、全アプリで共通とする。ページを開いた瞬間に反映し、ちらつかないこと。
- 「つぎの ひとへ」では消えない（端末の設定として扱う）。
- フォント：標準は読みやすい UD フォント「BIZ UDPゴシック」（1.18 から）。「⚙ きのう → 👾 ドットもじに する」で「DotGothic16」（ドットの文字）に切り替えられ、選んだものはブラウザに保存される（キー block-font2）。UD フォント「BIZ UDPゴシック」（Google Fonts から読み込む。読み込めないときは端末の Hiragino・Meiryo など）を行き来できる。
  - 画面の文字、ボタン、メニュー、ブロックの文字、解説書・あそびかた などすべてに適用する。Python のコード（エディタ・行番号・コンソール・コード例）は、桁がそろう「BIZ UDゴシック」にする。
  - ブロックのあるページでは、ブロックの大きさを文字に合わせるため、切り替え時にページを読み直す（組んだブロックは保存されているので消えない）。ブロックのテーマの文字も同じフォントにする。
  - 選んだフォントは端末に記憶し、全ページで共通とする（「つぎの ひとへ」では消えない）。ナイトモード・落ち着いた色と同時に使える。

### 4.8 実行時の表示
- 実行中は、いま動いているブロックを光らせる。
- 失敗したときは、理由と次にすることが分かるメッセージを出す（例：「💥 ぶつかっちゃった！」「❓ ここには ほしが ないよ！」）。
- 無限ループでページが固まらないように、動きの回数とくりかえしの回数に上限を設ける（上限に達したら「うごきが おおすぎるよ」「くりかえしが おわらないよ」と表示して止める）。
- 実行後に「つかった ブロック：〇こ ／ うごいた かず：〇かい」を表示する。

### 4.9 ステージクリア時の確認（めいろ・うちゅう・こわす・おく）
- クリアすると「🎉 ステージ クリア！ つぎの ステージに いきますか？」と次のステージ名を表示し、「はい」「いいえ」を出す。
  - 「はい」：次のステージへ移動する。
  - 「いいえ」：キャラクターをスタートに戻し、組んだブロックは残したまま同じステージに再挑戦できるようにする。Esc キーも「いいえ」と同じ。
- 目安のブロック数を超えたゴール、失敗、じゆうモードでは出さない。
- クリア直後に別のステージへ切り替えたときは、前のステージの確認ウィンドウを出さない。

### 4.10 「つぎの ひとへ」（リセット）
- 誤操作防止のため2回押しで実行する。1回目で項目が赤い「⚠ もういちど おすと リセット」に変わり、4秒以内にもう一度押すと実行する。
- 消すもの：全ステージで組んだブロック、クリアの ✅、ランダム迷路（世界）、修了証の名前。
- 残すもの：音、言語、ナイトモード、落ち着いた色の設定。
- 実行後はステージ1に戻り、「✨ リセットしたよ。つぎの ひと、がんばってね！」と表示する。

### 5.2 ⛏ ブロックでめいろ（maze.html）

**基本ルール**
- 5×5 マスの迷路で、たんけんか（オリジナルキャラクター）をスタートからゴールのダイヤ 💎 まで動かす。
- 「まえ」はヘルメットのライトが照らす方向とする。
- 盤面はドット絵で描く（草の地面、石ブロック＝岩、木の板＝スタート、ダイヤ鉱石＝ゴール）。通ったマスは土の道に変える。

**ブロック**
- まえに すすむ、みぎを むく、ひだりを むく
- 〇 かい くりかえす、ゴールに つくまで くりかえす
- もし ［まえ・みぎ・ひだり］ が あいていたら（そうでなければ）

**チュートリアル（ステージごとに使えるブロックを段階的に増やす）**

| ステージ | 学ぶこと | 目安ブロック数 |
|---|---|---|
| 1 まっすぐ すすもう | 順次 | – |
| 2 まがってみよう | 向き | – |
| 3 ながい みち | 長い手順 | – |
| 4 くりかえしを つかおう | 反復 | 5 |
| 5 かいだんを のぼろう | パターン発見 | 5 |
| 6 もし〜なら | 条件分岐・条件付き反復 | 4 |
| 7 みぎ？ ひだり？ | 条件分岐の入れ子 | 6 |
| 8 どんな めいろでも ゴール！ | 一般化（右手法）。ランダム迷路 30 個で自動テストし、全部ゴールでクリア | – |
| じゆうモード | ランダム迷路（岩 4／6／8 個）。必ずゴールできる配置のみ生成 | – |

- 目安を超えてゴールしたときは「〇こ いかに できるかな？」と促す（クリア扱いにしない）。
- 上限：動き 200 回、くりかえし 1,000 回。

### 5.2.1 ⛏ めいろの なかま（maze-junior.html ／ maze-key.html ／ maze-enemy.html）

**共通**
- 見た目・操作・効果音・クリア時の確認・修了証・先生モード・「つぎの ひとへ」・スマホの配置は、ブロックでめいろ と同じとする。進み具合はアプリごとに別に保存する（8章）。
- 3つのページは `maze.html` をもとに `tools/maze-variants/build.py` で作る。違う部分（ブロック・ステージと解答・せかいとシミュレーション・絵・効果音）は `tools/maze-variants/` の key.js／enemy.js／junior.js に置く。`maze.html` を直したときは作り直す。
- 盤面の大きさはステージごとに変えられる（4×4〜10×10）。1マスは 16×16 ドットの整数倍で描き、盤面の表示の大きさは同じにする。
- ランダム迷路・じゆうモードは置かない。
- めいろの ページ（ブロック4つ・Python版4つ）の「⚙ きのう」に「⛏ めいろを えらぶ…」を1項目だけ出す。押すと「めいろを えらぶ」の表（縦＝めいろ4種類、横＝🧩 ブロック／🐍 Python の 4×2）が開き、いま開いているマスを青く「いま ここ」、各マスにクリアしたステージ数（例：✅ 4 / 8、全部なら ✅ ぜんぶ）を表示する。マスを押すとそのページへ移る（Python版は Python の画面で開く）。Esc・×・外側を押すと閉じる。幅 600px 以下では画面の下から出す。ほかのアプリには出さない。
- 🐍 Python版（`python-maze-junior.html`／`python-maze-key.html`／`python-maze-enemy.html`）を置く（5.6 と同じしくみ。`tools/maze-variants/build_python.py` で作る）。命令は、やじるし：`up()` `down()` `left()` `right()`、かぎと とびら：`forward()` `turn_right()` `turn_left()` `pick_up()` `open_door()` と しらべる `key_here()` `door_ahead()` `is_open('front')`、てき：`forward()` `turn_right()` `turn_left()` `wait()` と しらべる `danger_ahead()` `is_open('front')`、くりかえしは `for i in range(〇):`・`while not at_goal():`。ブロックの アプリの「⚙ きのう」→「🐍 Python に きりかえる」で開く。
- 解答画像（`images/answers/mazejr1〜6`・`mazekey1〜4`・`mazeenemy1〜4`、英語は `en/`）、解説書、解説動画（`mazejr-`／`mazekey-`／`mazeenemy-`／`pymazejr-`／`pymazekey-`／`pymazeenemy-`）、授業スライド（09〜14）を、ほかのアプリと同じ形で用意する。

- 4×4（ステージ6のみ 5×5）の小さな迷路。かべは岩ではなく草むらにし、ブロックを大きめ（1.4倍）に表示する。

| ステージ | 学ぶこと | 目安 |

| 2 したへ まがろう | 2種類の矢印 | – |
| 3 かいだん | 交互の並び | – |
| 4 うえへ のぼろう | 4種類の矢印 | – |

**🗝 かぎと とびらの めいろ（状態）**
- 盤面にかぎ 🔑 ととびら 🚪 を置く。かぎの上で「かぎを ひろう」、とびらの前で「とびらを あける」。かぎ1つで、とびらが1つ開く。開いたとびらは通れる。
- 持っているかぎの数を盤面の左上に表示する。
- 条件のブロック「もし［まえが とびら・ここに かぎが ある］なら」を加える。「もし まえ が あいていたら」では、閉じたとびらは「あいていない」とする。
- 失敗のメッセージ：かぎを持たずにとびらへ進む「とびらが あかないよ。かぎは どこかな？」、持っているのに進む「とびらに ぶつかった！「とびらを あける」を つかおう」、かぎのない所で拾う「ここには かぎが ないよ」、前にとびらがない「まえに とびらが ないよ」、かぎがない「かぎを もっていないよ」。

| ステージ | 学ぶこと | 目安 |
|---|---|---|
| 1 かぎを ひろって とびらを あけよう | 新しい動作 | – |
| 2 かぎは どこ？ | 寄り道して取る（順番） | – |
| 3 とびらが 2つ | 反復 | 7 |
| 4 じぶんで かんがえる たんけんか | 条件つき反復＋3つの条件 | 8 |

### 5.6 🐍 Python版（python-draw.html ／ python.html ／ python-space.html ／ python-craft.html）
- おえかき（5.1）・めいろ（5.2）・うちゅう（5.3）・こわす・おく（5.4）のそれぞれに Python版を置き、プログラムを Python で表す。ブロックから文字のプログラミングへ進むための橋渡しとする。
- **しくみ**：4つのページは共通部品 `python-core.js` を使う。各ページは、もとのアプリの「せかい（マップ）・判定（simulate）・ドット絵・効果音」をそのまま使い、命令の対応・しらべる関数・ステージだけを定める。
  - Python のコードは、ページ内の小さな解釈器で読み取り、決まった命令だけの JavaScript（`forward();` など。各行に行番号の目印を付ける）に変換して、もとのアプリと同じ `simulate` で動かす。子どもが書いた文字をそのまま `eval` しない。
  - そのため、ぶつかる・水に落ちる・ほしがない などの判定とメッセージは、ブロックのアプリと同じになる。
- **2つのモード**（左上のタブで切り替え。最後に使ったモードを覚える）：

| モード | 画面 | 動作 |
|---|---|---|
| 🧩 ブロック（はじめはこちら） | 上：Blockly、下：「Python で かくと こうなるよ」（見るだけ） | ブロックを動かすたびに、同じ動きの Python のコードを下に表示する |
| 🐍 Python | コードエディタ＋命令ボタン | 自分で Python を書いて実行する |

- **ブロック ⇄ Python の変換**
  - ブロック → Python：ブロック1つが Python の1行になる。「そうでなければ」の中が「もし」1つだけのときは `elif` にまとめる。中が空のくりかえし・もしは `pass` にする。
  - Python → ブロック：書いたコードを読み取ってブロックを組み直す。`#` のコメントはブロックにないため消える（そのことを表示する）。
  - 文法エラーがあるとき、またはブロックにできない書き方（`while True:`、`while is_open(...)`、`if not ...`、`if at_goal()` など）のときは、行番号を示して Python モードのままにする。
  - いちばん上のかたまりだけを実行し、離れたブロックがあるときは知らせる。
- **ブロックと Python の対応**（画面の「🧩 ブロックと 🐍 Python の たいおう」に表で示す。ブロックの文字と色は もとのアプリと同じ）：

| ブロック | Python | アプリ |
|---|---|---|
| まえに すすむ ／ みぎを むく ／ ひだりを むく | `forward()` ／ `turn_right()` ／ `turn_left()` | 4つとも |
| ⭐ ほしを ひろう | `pick_up()` | うちゅう |
| ⛏ まえの ブロックを こわす ／ 🧱 まえに ブロックを おく | `mine()` ／ `place()` | こわす・おく |
| 〇かい くりかえす | `for i in range(〇):`（〇は 1〜50） | 4つとも |
| ゴールに つくまで くりかえす | `while not at_goal():` | めいろ・こわす・おく |
| 🚀 ミッション クリアまで くりかえす | `while not mission_done():` | うちゅう |
| もし （まえ／みぎ／ひだり）が あいていたら | `if is_open('front'):`（`'right'`／`'left'`） | めいろ・うちゅう |
| もし ここに ⭐ ほしが あったら | `if has_star():` | うちゅう |
| もし まえが （いしブロック／みず／すすめる みち） だったら | `if front_is('stone'):`（`'water'`／`'path'`） | こわす・おく |
| まえに 〇 ほ すすむ ／ うしろに 〇 ほ さがる | `forward(〇)` ／ `back(〇)` | おえかき |
| みぎに 〇 ど まわる ／ ひだりに 〇 ど まわる | `right(〇)` ／ `left(〇)` | おえかき |
| ペンのいろを 〇 にする ／ ペンのふとさを 〇 にする | `pen_color('red')`（black／red／blue／green／yellow／orange／purple／pink／random） ／ `pen_width(〇)` | おえかき |
| ペンを あげる ／ おろす ／ まんなかに もどる | `pen_up()` ／ `pen_down()` ／ `home()` | おえかき |
| 〇 を A から B まで C ずつ（カウント） | `for i in range(A, B + 1, C):`（`range` の「おわり」は含まないため B + 1） | おえかき |
| かず ／ へんすう ／ けいさん（＋ − × ÷ ^） | `80` ／ `i` ／ `+ - * / **` | おえかき |
| そうでなければ | `else:`（中が「もし」だけなら `elif ...:`） | 4つとも |

- 「もし」の各ブロックには、「そうでなければ」付きの形も用意する（Python で `else` や `elif` を書いたときにブロックへ戻せるようにする）。
- **使える Python**：上表の命令に加えて `pass`、`while True:`、`not`、`#` コメント。字下げはスペース4つ（Tab キーでスペース4つを入れる）。
- **おえかきの Python（数・変数・計算）**：
  - 命令の `()` の中に、数・変数・計算の式を書ける（例：`forward(i * 4)`、`right(360 / n)`）。使える計算は `+ - * / // % **` と `( )`、マイナスの数。
  - `for 変数 in range(おわり)`／`range(はじめ, おわり)`／`range(はじめ, おわり, ふやす かず)`。`range` の中にも式や変数を書ける（例：`for i in range(n):`）。変数は、それより前の `for` で作ったものだけ使える（ないときは NameError）。
  - ブロックとの対応：変数を使わない `for i in range(〇):` は「〇かい くりかえす」、それ以外は「カウント（〇 を A から B まで C ずつ）」。数・変数・計算は「かず」「へんすう」「けいさん」のブロック。`//` と `%`、ふやす かず が式の `range` はブロックにできない（Python のまま）。ブロック → Python では、くりかえしの変数名を `i`・`k`・`j` の順に、外側と重ならないように付ける。
  - お手本との一致の判定・描き方は ブロックでおえかき と同じ（お手本の線の 95% 以上をなぞり、余分な線が 5% 未満なら正解。60% 以上は「おしい」）。
- **ステージ**（ステージの盤面は もとのアプリと同じ。ランダム・じゆうモードは置かない）：

| アプリ | # | タイトル | 学ぶこと |
|---|---|---|---|
| めいろ | 1〜5 | まっすぐ すすもう／まがってみよう／for で くりかえそう／while と if／elif で 3つに わけよう | 順次、`()`、`for` とコロン・字下げ、`while not`・`if`／`else`、`elif` |
| うちゅう | 1〜6 | ほしを ひろおう／まがって あつめよう／for で あつめよう／ほしの かいだん／`if has_star():`／`while not mission_done():` | `pick_up()`、順次、`for` の中に2行以上、パターン、入れ子の字下げ（8つ）、`while not` と2つの `if` |
| おえかき | ①〜⑨ | 六角形／ほし／まる／まど／はな／しかくい うずまき／ならんだ たかくけい／ゆきの けっしょう／ほしの うずまき（お手本は ブロックでおえかき と同じ） | `forward(80)`・`right(60)`、`for` と字下げ、入れ子、`range(10, 201, 10)` と変数、`360 / n`、`i * 4`、`pen_color('random')` |
| こわす・おく | 1〜7 | こわして すすもう／はしを かけよう／for で こわそう／ながい はし／`if front_is('stone'):`／elif で いしと みず／うずまきの どうくつ | `mine()`・`place()`、持っている数、`for`、`if front_is(...)`、`elif`、`if`・`elif`・`elif`・`else` の4分岐 |

- 使えるブロックはステージごとに増やす（もとのアプリと同じ順）。
- **実行**：コードを読み取ってから動かす。動いている行を黄色で光らせ、ブロックモードでは対応するブロックも光らせる。上限は もとのアプリと同じ（めいろ：動き 200回、うちゅう：400回、こわす・おく：300回、おえかき：命令 20,000）。おえかきは線を1本ずつ描き、はやさで待ち時間を変える。クリア時は もとのアプリと同じ演出（うちゅう：ロケット発射、こわす・おく：たからばこが開く）。
- **エラー表示**：本物の Python と同じエラー名に、ひらがなの説明と行番号をつける。エラーの行は赤く光らせ、下のコンソールにも `File "main.py", 〇ぎょうめ` の形で表示する。

| 原因 | 表示（例） |
|---|---|
| 行末の `:` 忘れ | SyntaxError：さいごに「:」（コロン）が ひつようだよ |
| 字下げのずれ | IndentationError：じさげ（あたまの スペース）が そろっていないよ |

## 7. 非機能要件

### 7.1 動作環境
- 最新の Chrome／Edge／Safari（iPad 含む）で動くこと。
- サーバー側の処理は不要とする（GitHub Pages の静的配信のみ）。Firebase は任意とする。
- `file://` で直接開いた場合は、ローカルモード以外の Firebase 機能は動かない（`https://` で開く）。

### 7.2 使いやすさ・アクセシビリティ
- 子ども向けの表示はひらがな中心とし、英語はやさしい表現とする。
- 失敗メッセージは、次の行動が分かる表現とする。
- 重要な操作（リセット、全削除）は2回押しで確認する。
- 音の消音、ナイトモード、落ち着いた色を選べるようにする。
- タッチ操作で使えること（メニュー項目 48px 以上、ドット絵エディタはポインタ操作対応）。スマホ（幅 600px 以下）では、ボタンを 40〜52px 以上にし、ブロックはタップで組めること（4.3.1）。

### 7.3 安全・プライバシー
- 子どもの名前・個人情報は保存しない（修了証の名前も保存しない）。
- Firebase では匿名認証を使い、データベースのルールで書き込みを制限する（9章）。
- Firebase の API キーは公開してよい値とし、安全はルールで守る。

### 7.4 保守性
- 共通部品は `common.css`／`i18n.js`／`certificate.js` に集約する。
- 新しいアプリは、共通ファイルを読み込み、テーマの色（CSS 変数）を決めるだけで見た目がそろうようにする。
- ページ間のリンクは `i18n.js` の一覧に1行足すだけで、全ページのヘッダーに反映されるようにする。
- 解説書のデータ（`guide-data.js`）と解説動画は、アプリのステージ定義と解答データから作る。ステージを変えたときは作り直す。
- おだい・ステージは配列（`CHALLENGES`／`LEVELS`）に追加するだけで増やせるようにする。
- ソースコードのコメントはひらがな中心で、中学生でも読めるようにする。

### 7.5 著作権・名称
- Blockly（Apache License 2.0）を使う。
- マインクラフト、Viscuit などの名称・キャラクター・画面デザイン・ロゴは使わない。作品名や README にもその名称を出さない。
- ドット絵・効果音・キャラクターはすべてオリジナルとする。

## 9. Firebase 連携の仕様（すいぞくかん）

### 9.1 データ構造（Realtime Database）

```
rooms/
  {部屋番号 5文字}/
    owner:     作った先生の匿名 uid
    createdAt: 作成時刻（サーバー時刻）
    fish/
      {自動ID}/
        px:   ドット絵（16進 256文字）
        prog: 泳ぎ方（ブロックの JSON、8000文字まで）
        by:   入れた人の匿名 uid
        t:    サーバー時刻
```

### 9.2 権限（database.rules.json）

| 操作 | 許可する人 |
|---|---|
| 部屋を作る | 匿名ログインした人（作った人が先生になる） |
| 魚を入れる | 部屋が存在するとき、匿名ログインした人 |
| 魚を見る | 部屋番号を知っている人 |
| 魚を消す | その部屋の先生、または入れた本人 |
| 全部消す | その部屋の先生 |
| 他人の魚を書きかえる | だれもできない |
| 決められた項目以外のデータ | 受け付けない |

### 9.3 運用上の注意
- 無料プラン（Spark）は同時接続 100 まで（1クラスなら十分）。
- 魚を消せるのは、部屋を作ったのと同じブラウザだけ。部屋作りと水族館の表示は同じ PC で行う。
- ロケーションはシンガポール（asia-southeast1）を推奨する。

### 自動テストで確認済みの事項
- 全アプリ・全課題の解答が、日本語・英語の両方でクリアできること。
- めいろステージ8の右手法はランダム迷路 900 個、うちゅうステージ7の解答はランダムな宇宙 1,000 個以上で全クリアできること。
- 失敗パターン（ぶつかる、拾えない、こわせない、無限ループ等）で正しいメッセージが出ること。
- ヘッダーが 16ページ × 2言語 × 14通りの画面幅で1行に収まること。
- めいろの なかま：やじるし 6・かぎと とびら 4・てき 4 ステージの解答が、日本語・英語でクリアできること。かぎを持たずにとびらへ進む・かぎのない所で拾う・前にとびらがない・かぎを持っているのに進む・草むらにぶつかる・矢印が足りない で、正しいメッセージが出ること。てき の4ステージは「まつ」を使わない解き方では、すべてスライムにつかまること。実行の動き・音・クリア・全ステージクリアで修了証の項目が出ること。めいろの ページ8つの「⚙ きのう」に「⛏ めいろを えらぶ…」が出て、表に 8マスと「いま ここ」・クリア数（ブロックの true の並び、Python版の番号の並びの両方）が正しく出ること、マスで移動でき、Esc で閉じること、ほかのアプリには出ないこと、スマホでは下から出ること。スマホの配置で棚に各ステージのブロックが出ること。
