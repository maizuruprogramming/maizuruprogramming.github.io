## 1. 目的と背景

### 1.1 目的
- 小・中学生が、ブロックを組み合わせるだけでプログラミングの基本（順次・反復・条件分岐・変数・アルゴリズムの一般化）を楽しく学べる教材を作る。
- HTML だけで動き、GitHub で公開・配布できる形にする。インストールやビルドは不要とする。
- 授業、科学イベント（例：「青少年のための科学の祭典」）、家庭学習で使えるようにする。

### 1.2 方針
- ブロックエディタには Google の **Blockly**（Apache License 2.0）を使う。
- 見た目はマインクラフト風のドット絵とする。ただし、既存作品のキャラクター・テクスチャ・ロゴ・名称は使わず、オリジナルのデザインで雰囲気を寄せる。
- 「みんなの作品が1つの画面で泳ぐ」体験（Viscuit の水族館のような体験）を、名称や画面デザインはまねせずに、オリジナルの形で実現する。

## 2. 対象利用者と利用場面

| 利用者 | 主な使い方 |
|---|---|
| 小学生（低〜高学年） | ひらがな中心の画面で、迷路・おえかきを解く |
| 中学生 | 変数・入れ子・アルゴリズムの課題、英語モード |
| 先生・保護者 | 解答の読み込み（先生モード）、水族館の部屋作り、解答集を使った解説、修了証の印刷 |
| イベント参加者 | 1台の端末を交代で使う（「つぎの ひとへ」でリセット） |

想定端末：PC（Chrome / Edge / Safari）、iPad（横 1024〜1366px、縦 744〜1024px）、電子黒板・プロジェクター。

## 4. 共通要件（全アプリ）

### 4.1 画面構成
- 左にブロックを組む場所（Blockly）、右に課題パネル・盤面・メッセージを置く。
- 幅 900px 以下では、ブロックの場所（画面の高さの 60%）と盤面を縦に並べる。
- ヘッダーには、タイトル、他アプリへのリンク、▶ じっこう、↺ もどす、📖 こたえ（先生モードのみ）、⚙ きのう を置く。

### 4.2 デザインの統一
- ヘッダー（高さ 56px）、ボタン、パネル（幅 400px）、右列（幅 440px）、盤面の枠（400×400px＋黒枠）、メッセージ、クリアのウィンドウの形と大きさは `common.css` で全アプリ共通とする。
- 各ページは CSS 変数（`--hdr-bg` `--panel-bg` など）でテーマの色だけを決める。

| アプリ | テーマ |
|---|---|
| おえかき | 空とノート |
| めいろ | 草と土 |
| うちゅう | 宇宙 |
| こわす・おく | 石と洞くつ |
| すいぞくかん | 海 |

- 「▶ じっこう」ボタンは全アプリ同じ緑とする。
- 文字はドットフォント（DotGothic16）に統一する。子ども向けの表示はひらがな中心とする。

### 4.3 ヘッダーの1行表示（iPad 対応）
画面幅に応じて段階的に文字を隠し、ヘッダーを常に1行に収める。

| 画面幅 | 表示 |
|---|---|
| 1441px 以上 | すべて文字付き |
| 1440px 以下 | アプリのリンクはアイコンだけ |
| 1240px 以下 | 「▶ じっこう」「⚙ きのう」以外のボタンはアイコンだけ |
| 860px 以下 | タイトルと「⚙ きのう」もアイコンだけ |

- 受け入れ基準：5アプリ × 2言語 × 14通りの幅（744〜1920px）で、ヘッダーのボタン・リンクが2行にならないこと。

### 4.4 ⚙「きのう」メニュー
「音」「言語選択」「リセット」などは、ヘッダーの「⚙ きのう」（英語では「⚙ Settings」）ボタンにまとめる。押すとメニューが開く。

| メニュー項目 | 動作 | 対象アプリ |
|---|---|---|
| 🔊 おと：オン／オフ | 効果音の切り替え。メニューは開いたまま状態を表示 | めいろ・うちゅう・こわす・おく |
| 🌐 English（えいご）に する | 日本語／英語の切り替え | 全アプリ |
| 🌙 ナイトモードに する | 画面全体を暗い色にする（もう一度で「☀️ ふつうの あかるさに もどす」） | 全アプリ |
| 🎨 おちついた いろに する | あざやかさとコントラストを下げる（もう一度で「🌈 もとの いろに もどす」） | 全アプリ |
| 📜 しゅうりょうしょうを みる | 修了証を表示する（全ステージクリア時のみ表示） | めいろ・うちゅう・こわす・おく |
| 🔄 つぎの ひとへ | 次の人のためのリセット（2回押しで実行） | めいろ・うちゅう・こわす・おく |

- メニューの外をタップするか Esc キーで閉じる。
- 項目は指で押しやすい高さ（48px 以上）とする。

### 4.5 日本語／英語の切り替え
- 画面の文字、ブロックの文字、ステージ・おだいの説明とヒント、メッセージ、ダイアログ、修了証を切り替える。
- Blockly 標準の文言（右クリックメニュー等）も、対応する言語ファイルを読み込んで切り替える。
- 標準ブロックの表示は日本語ではひらがなに固定する（例：「4 かい くりかえす」「i を 1 から 10 まで 1 ずつ かぞえる」）。
- 選んだ言語は端末に記憶し、全アプリで共通とする。URL の `?lang=en`／`?lang=ja` でも指定できる。
- 切り替えても、組んだブロックと進み具合は消えない。
- 英語は小学生にも読めるやさしい表現とする。

### 4.6 ナイトモード・落ち着いた色
- ナイトモード：背景・パネル・ボタン・メニューを暗い色にし、盤面と絵は明るさを約 78% に下げる。暗くしても、おえかきのお手本の線と描いた線が見えること。
- 落ち着いた色：画面全体の彩度を 45%、コントラストを 90% にする。テーマの雰囲気は残す。
- 2つは同時に使える。設定は端末に記憶し、全アプリで共通とする。ページを開いた瞬間に反映し、ちらつかないこと。
- 「つぎの ひとへ」では消えない（端末の設定として扱う）。

### 4.7 効果音
- Web Audio で 8ビット風の音をその場で合成し、音声ファイルは使わない。
- ブラウザの制限のため、最初にボタンを押したときから鳴らす。

| 場面 | 音 |
|---|---|
| 前に進む | 足音（左右で高さを変える。宇宙は「ぽよん」） |
| 右を向く／左を向く | 「ひゅっ↑」／「ひゅっ↓」（聞くだけで左右が分かる） |
| ぶつかる | 「ゴンッ」 |
| ステージクリア | 「ドミソド〜」のファンファーレ |
| 目安オーバーでゴール | 短い2音 |
| 失敗（ゴールに着かない等） | 下がる3音 |
| 全クリア | 長めのファンファーレ |
| 宇宙：星を拾う／全部集める／発射 | 「ピロン」／上がる4音／「ゴゴゴ…」 |
| こわす・おく：こわす／置く／水に落ちる／宝箱 | 「カッカッ ガラッ」／「ゴトッ」／「ポチャン」／上がる4音 |

### 4.8 実行時の表示
- 実行中は、いま動いているブロックを光らせる。
- 失敗したときは、理由と次にすることが分かるメッセージを出す（例：「💥 ぶつかっちゃった！」「❓ ここには ほしが ないよ！」）。
- 無限ループでページが固まらないように、動きの回数とくりかえしの回数に上限を設ける（上限に達したら「うごきが おおすぎるよ」「くりかえしが おわらないよ」と表示して止める）。
- 実行後に「つかった ブロック：〇こ ／ うごいた かず：〇かい」を表示する。

### 4.9 ステージクリア時の確認（めいろ・うちゅう・こわす・おく）
- クリアすると「🎉 ステージ クリア！ つぎの ステージに いきますか？」と次のステージ名を表示し、「はい」「いいえ」を出す。
  - 「はい」：次のステージへ移動する。
  - 「いいえ」：キャラクターをスタートに戻し、組んだブロックは残したまま同じステージに再挑戦できるようにする。Esc キーも「いいえ」と同じ。
- 目安のブロック数を超えたゴール、失敗、じゆうモードでは出さない。
- クリア直後に別のステージへ切り替えたときは、前のステージの確認ウィンドウを出さない。

### 4.10 「つぎの ひとへ」（リセット）
- 誤操作防止のため2回押しで実行する。1回目で項目が赤い「⚠ もういちど おすと リセット」に変わり、4秒以内にもう一度押すと実行する。
- 消すもの：全ステージで組んだブロック、クリアの ✅、ランダム迷路（世界）、修了証の名前。
- 残すもの：音、言語、ナイトモード、落ち着いた色の設定。
- 実行後はステージ1に戻り、「✨ リセットしたよ。つぎの ひと、がんばってね！」と表示する。

### 4.11 先生モード
- URL に `?sensei` を付けたときだけ「📖 こたえ」ボタンを表示する（子どもの画面には出さない）。
- 押すと、選んでいる課題の解答ブロックをワークスペースに読み込む（組んでいたブロックは置きかわる）。

### 4.12 📜 修了証（めいろ・うちゅう・こわす・おく）
- じゆうモード以外の全ステージをクリアした瞬間に表示する。閉じたあとは、次のステージ（じゆうモード）への確認を出す。
- 記載内容：

| 項目 | 日本語 | 英語 |
|---|---|---|
| タイトル | 修了証（ふりがな「しゅうりょうしょう」） | Certificate of Completion |
| 名前 | 「〇〇 さん」（空欄可） | 名前のみ（空欄可） |
| 本文 | アプリ名と、がんばりをたたえる文 | 同左 |
| 日付 | 端末の日付（例：2026年11月8日） | 端末の日付（例：November 8, 2026） |
| 発行者 | 舞鶴工業高等専門学校　井上泰仁 | National Institute of Technology (KOSEN), Maizuru College / Yasuhito Inoue |

- 名前はその場で入力し、修了証にすぐ反映する。名前は保存しない（共用端末への配慮）。
- 「🖨 いんさつ」で A4 横 1枚に印刷し、「💾 がぞうで ほぞん」で PNG 画像として保存する。
- 「⚙ きのう」メニューから何度でも再表示できる。
- 四隅にアプリごとのアイコンを入れる（めいろ ⛏💎、うちゅう 🚀⭐、こわす・おく 🧱⛏）。

## 5. アプリ別の機能要件

### 5.1 🐢 ブロックでおえかき（index.html）

**ブロック**

| 分類 | ブロック |
|---|---|
| うごき | まえに 〇 ほ すすむ／うしろに 〇 ほ さがる／みぎに 〇 ど まわる／ひだりに 〇 ど まわる／まんなかに もどる |
| ペン | ペンのいろを ［くろ・あか・あお・みどり・きいろ・オレンジ・むらさき・ピンク・ランダム］ にする／ペンのふとさ／ペンを あげる・おろす |
| くりかえし | 〇 かい くりかえす／i を 〇 から 〇 まで 〇 ずつ かぞえる |
| かず | 数、四則計算、ランダムな数 |
| へんすう | 変数の作成・利用 |

**おだい（課題）モード**
- リストからおだいを選ぶと、お手本をうすい灰色で表示する。
- 実行後、お手本と描いた線の位置を比べて自動判定する。
  - お手本の 95% 以上をなぞれていて、はみ出しも 5% 未満なら「🎉 せいかい！」。
  - お手本の 60% 以上なら「おしい！ 〇% まで かけたよ」。
  - それ以外は「お手本と ちがうみたい。ヒントを みてみよう」。
- 判定するのは線の形と位置だけで、色・太さは自由とする。
- 各おだいにヒントボタンを付ける。

| # | おだい | 難しさ | 学ぶこと |
|---|---|---|---|
| ① | 六角形 | ★ | くりかえし、外角＝360÷角の数 |
| ② | ほし | ★★ | 2周（720°）回る図形 |
| ③ | まる | ★★ | 短い直線で円を近似する |
| ④ | まど | ★★★ | 入れ子のくりかえし |
| ⑤ | はな | ★★★ | 入れ子＋回転対称 |
| ⑥ | しかくい うずまき | ★★★★ | 変数を長さに使う |
| ⑦ | ならんだ たかくけい | ★★★★ | 変数＋計算（360÷n） |
| ⑧ | ゆきの けっしょう | ★★★★★ | 手順の分解、元の場所に戻る |
| ⑨ | ほしの うずまき | ★★★★★ | 変数×計算＋回転 |

**その他**
- はやさは 1〜21（21 は一瞬で描く）とする。
- 命令の上限は 20,000 回とする。
- 組んだブロックと選んだおだいは端末に保存する。

### 5.2 ⛏ ブロックでめいろ（maze.html）

**基本ルール**
- 5×5 マスの迷路で、たんけんか（オリジナルキャラクター）をスタートからゴールのダイヤ 💎 まで動かす。
- 「まえ」はヘルメットのライトが照らす方向とする。
- 盤面はドット絵で描く（草の地面、石ブロック＝岩、木の板＝スタート、ダイヤ鉱石＝ゴール）。通ったマスは土の道に変える。

**ブロック**
- まえに すすむ、みぎを むく、ひだりを むく
- 〇 かい くりかえす、ゴールに つくまで くりかえす
- もし ［まえ・みぎ・ひだり］ が あいていたら（そうでなければ）

**チュートリアル（ステージごとに使えるブロックを段階的に増やす）**

| ステージ | 学ぶこと | 目安ブロック数 |
|---|---|---|
| 1 まっすぐ すすもう | 順次 | – |
| 2 まがってみよう | 向き | – |
| 3 ながい みち | 長い手順 | – |
| 4 くりかえしを つかおう | 反復 | 5 |
| 5 かいだんを のぼろう | パターン発見 | 5 |
| 6 もし〜なら | 条件分岐・条件付き反復 | 4 |
| 7 みぎ？ ひだり？ | 条件分岐の入れ子 | 6 |
| 8 どんな めいろでも ゴール！ | 一般化（右手法）。ランダム迷路 30 個で自動テストし、全部ゴールでクリア | – |
| じゆうモード | ランダム迷路（岩 4／6／8 個）。必ずゴールできる配置のみ生成 | – |

- 目安を超えてゴールしたときは「〇こ いかに できるかな？」と促す（クリア扱いにしない）。
- 上限：動き 200 回、くりかえし 1,000 回。

### 5.3 🚀 うちゅうで ほしあつめ（space.html）

**基本ルール**
- 宇宙飛行士で星 ⭐ をすべて拾い、ロケット 🚀 に乗るとクリアし、ロケットが発射するアニメーションを出す。
- 星を集め終わる前にロケットを通っても、クリアにはならない。
- 星のないマスで「ひろう」と失敗とする。
- 盤面の上に「⭐ あつめた ほし：〇 / 〇」を表示する。

**ブロック**
- まえに すすむ、みぎを むく、ひだりを むく
- ⭐ ほしを ひろう
- もし ここに ⭐ ほしが あったら
- 〇 かい くりかえす、🚀 ミッション クリアまで くりかえす
- もし ［まえ・みぎ・ひだり］ が あいていたら（そうでなければ）

**ステージ**

| ステージ | 学ぶこと | 目安ブロック数 |
|---|---|---|
| 1 ほしを ひろおう | 順次＋拾う | – |
| 2 まがって あつめよう | 向きと順番 | – |
| 3 くりかえしで あつめよう | 反復 | 4 |
| 4 ほしの かいだん | パターン発見 | 6 |
| 5 もし ほしが あったら | 条件分岐（その場を調べる） | 4 |
| 6 ミッション クリアまで | 条件付き反復＋条件分岐 | 6 |
| 7 どんな うちゅうでも！ | 一般化（右手法＋調べて拾う）。ランダムな宇宙 30 個で自動テスト | – |
| じゆうモード | ランダムな宇宙（隕石 4／6／8 個、星 3 個） | – |

- ランダムな宇宙では、右手法で通るマスの上に星を置き、必ず解けるようにする。
- 上限：動き 400 回、くりかえし 2,000 回。

### 5.4 🧱 こわして つくる ぼうけん（craft.html）

**基本ルール**
- つるはしで石ブロックを「こわす」と、そのブロックが持ち物に入る。
- 水の上に「おく」と板の橋になり、渡れる。
- 宝箱に着くとクリアとする。

**マスの種類**

| マス | 説明 |
|---|---|
| 草・土 | 進める |
| 石ブロック | こわせる（こわすと土になり、持ち物 +1） |
| かたい岩 | こわせない |
| 水 | 進むと落ちる。ブロックを置くと橋になる（持ち物 −1） |
| 宝箱 | ゴール |

- 草の上にブロックを置くと石ブロックになる。
- 「もっている ブロック：〇こ」を表示する。

**ブロック**
- まえに すすむ、みぎを むく、ひだりを むく
- ⛏ まえの ブロックを こわす、🧱 まえに ブロックを おく
- 〇 かい くりかえす、ゴールに つくまで くりかえす
- もし まえが ［いしブロック・みず・すすめる みち］ だったら（そうでなければ）

**失敗メッセージ**
- 石にぶつかる、水に落ちる、かたい岩はこわせない、こわすものがない、ブロックを持っていない、そこには置けない、の6種類。

**ステージ**

| ステージ | 学ぶこと | 目安ブロック数 |
|---|---|---|
| 1 こわして すすもう | こわす | – |
| 2 はしを かけよう | こわす→持つ→置く | – |
| 3 くりかえして こわそう | 反復 | 4 |
| 4 ながい はし | 持っている3こを使い切る反復 | 4 |
| 5 もし いしが あったら | 条件分岐 | 4 |
| 6 いしと みず | 2つの条件分岐、持ち物の増減 | 6 |
| 7 うずまきの どうくつ | 条件付き反復＋3つの条件分岐 | 8 |
| じゆうモード | ランダムな世界（かたい岩 5・石 4・水 3、持ち物 3 でスタート） | – |

- じゆうモードは、石と水を通れるものとして必ずゴールできる配置のみ生成する。
- 上限：動き 300 回、くりかえし 2,000 回。

### 5.5 🐟 おさかな すいぞくかん（aquarium.html）

**流れ**
1. 16×16 マスのドット絵で魚を描く（15色＋けしゴム、左右反転、お手本）。
2. ブロックで泳ぎ方を決め、プレビューで確かめる。
3. 部屋番号を入れて「🌊 すいぞくかんに いれる」を押すと、先生の大きな画面に魚が現れる。画面に「🐟 あたらしい なかまが きたよ！」と出し、魚が上から入ってくる。

**ブロック**
- 🐟 はじまったら（この下に組んだブロックが、最後まで行くと最初から繰り返される）
- まえに 〇 すすむ、みぎ／ひだりに 〇 ど まわる、ランダムに むきを かえる、［みぎ・ひだり・うえ・した］ を むく、かべに ついたら はねかえる
- 〇 びょう まつ、はやさを 〇 にする（1〜10）、おおきさを 〇 % にする（30〜300）
- 〇 かい くりかえす、数、ランダムな数

**水族館の画面**
- URL：`?view=tank&room=部屋番号`
- 内容：水のグラデーション、光のすじ、砂、揺れる海藻、泡。魚は左向きでもさかさまにならない。
- 先生（部屋を作った人）だけの操作：「🗑 けすモード」（魚をクリックで削除）、「ぜんぶ けす」（2回押し）。
- 全画面表示ボタンを付ける。

**モード**

| モード | 条件 | 内容 |
|---|---|---|
| ローカルモード | `firebase-config.js` が空 | 1台の端末で遊ぶ（別タブの水族館に反映） |
| Firebase モード | 設定あり | クラス全員の魚がリアルタイムで先生の画面に集まる |

**先生の準備**
- `aquarium.html?sensei` で「あたらしい へやを つくる」を押すと、部屋番号を発行する（5文字。O・0・I・1 など紛らわしい文字は使わない）。
- 水族館の URL と、子どもに配る URL を表示する。

**制限**
- 1台の端末から1つの部屋に入れられる魚は 5 匹まで。
- 表示する魚は最新 200 匹まで。

**安全**
- 送られてきたプログラムを JavaScript として実行しない。決められたブロックの JSON だけを解釈して動かす。
- 不正なデータや極端な数値を送られても止まらないこと。

## 7. 非機能要件

### 7.1 動作環境
- 最新の Chrome／Edge／Safari（iPad 含む）で動くこと。
- サーバー側の処理は不要とする（GitHub Pages の静的配信のみ）。Firebase は任意とする。
- `file://` で直接開いた場合は、ローカルモード以外の Firebase 機能は動かない（`https://` で開く）。

### 7.2 使いやすさ・アクセシビリティ
- 子ども向けの表示はひらがな中心とし、英語はやさしい表現とする。
- 失敗メッセージは、次の行動が分かる表現とする。
- 重要な操作（リセット、全削除）は2回押しで確認する。
- 音の消音、ナイトモード、落ち着いた色を選べるようにする。
- タッチ操作で使えること（メニュー項目 48px 以上、ドット絵エディタはポインタ操作対応）。

### 7.3 安全・プライバシー
- 子どもの名前・個人情報は保存しない（修了証の名前も保存しない）。
- Firebase では匿名認証を使い、データベースのルールで書き込みを制限する（9章）。
- Firebase の API キーは公開してよい値とし、安全はルールで守る。

### 7.4 保守性
- 共通部品は `common.css`／`i18n.js`／`certificate.js` に集約する。
- 新しいアプリは、共通ファイルを読み込み、テーマの色（CSS 変数）を決めるだけで見た目がそろうようにする。
- おだい・ステージは配列（`CHALLENGES`／`LEVELS`）に追加するだけで増やせるようにする。
- ソースコードのコメントはひらがな中心で、中学生でも読めるようにする。

### 7.5 著作権・名称
- Blockly（Apache License 2.0）を使う。
- マインクラフト、Viscuit などの名称・キャラクター・画面デザイン・ロゴは使わない。作品名や README にもその名称を出さない。
- ドット絵・効果音・キャラクターはすべてオリジナルとする。

## 9. Firebase 連携の仕様（すいぞくかん）

### 9.1 データ構造（Realtime Database）

```
rooms/
  {部屋番号 5文字}/
    owner:     作った先生の匿名 uid
    createdAt: 作成時刻（サーバー時刻）
    fish/
      {自動ID}/
        px:   ドット絵（16進 256文字）
        prog: 泳ぎ方（ブロックの JSON、8000文字まで）
        by:   入れた人の匿名 uid
        t:    サーバー時刻
```

### 9.2 権限（database.rules.json）

| 操作 | 許可する人 |
|---|---|
| 部屋を作る | 匿名ログインした人（作った人が先生になる） |
| 魚を入れる | 部屋が存在するとき、匿名ログインした人 |
| 魚を見る | 部屋番号を知っている人 |
| 魚を消す | その部屋の先生、または入れた本人 |
| 全部消す | その部屋の先生 |
| 他人の魚を書きかえる | だれもできない |
| 決められた項目以外のデータ | 受け付けない |

### 9.3 運用上の注意
- 無料プラン（Spark）は同時接続 100 まで（1クラスなら十分）。
- 魚を消せるのは、部屋を作ったのと同じブラウザだけ。部屋作りと水族館の表示は同じ PC で行う。
- ロケーションはシンガポール（asia-southeast1）を推奨する。

## 10. 制約・前提・確認事項

| 区分 | 内容 |
|---|---|
| 未確認 | 開発環境から Blockly の CDN と Firebase に接続できなかったため、Blockly の実際のブロック画面（ブロックの見た目、テーマ、ナイトモード時の色、解答ブロックの読み込み）と本物の Firebase・セキュリティルールは実機で未確認。動作ロジックは代替部品を使った自動テストで確認済み |
| 要確認 | 英語版の発行者表記「National Institute of Technology (KOSEN), Maizuru College / Yasuhito Inoue」が正しいか |
| 要確認 | 効果音の音量・聞こえ方（実機での確認が必要） |
| 前提 | Blockly v11 の CDN（unpkg）と Google Fonts に接続できるネットワーク環境 |
| 前提 | 解答画像のブロックは Blockly の見た目に似せて別途描いたもので、角の形などは実際の画面と少し異なる |
| 仕様 | ブロックの形はテーマに合わせて、めいろ・こわす・おくは四角（geras）、そのほかは丸み（zelos） |

### 自動テストで確認済みの事項
- 全アプリ・全課題の解答が、日本語・英語の両方でクリアできること。
- めいろステージ8の右手法はランダム迷路 900 個、うちゅうステージ7の解答はランダムな宇宙 1,000 個以上で全クリアできること。
- 失敗パターン（ぶつかる、拾えない、こわせない、無限ループ等）で正しいメッセージが出ること。
- ヘッダーが 5アプリ × 2言語 × 14通りの画面幅で1行に収まること。
- 修了証が全ステージクリア時のみ表示され、A4 横 1枚で印刷できること。
- すいぞくかんの部屋作り→送信→表示→削除の流れ（代替 Firebase）、および不正データへの耐性。
