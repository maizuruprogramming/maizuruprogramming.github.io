## 1. 目的と背景

### 1.1 目的
- 小・中学生が、ブロックを組み合わせるだけでプログラミングの基本（順次・反復・条件分岐・変数・アルゴリズムの一般化）を楽しく学べる教材を作る。
- HTML だけで動き、GitHub で公開・配布できる形にする。インストールやビルドは不要とする。
- 授業、科学イベント（例：「青少年のための科学の祭典」）、家庭学習で使えるようにする。
- 解説書・解説動画・解答集・修了証をそろえ、先生や保護者が準備や説明に使えるようにする。

### 1.2 方針
- ブロックエディタには Google の **Blockly**（Apache License 2.0）を使う。
- 見た目はマインクラフト風のドット絵とする。ただし、既存作品のキャラクター・テクスチャ・ロゴ・名称は使わず、オリジナルのデザインで雰囲気を寄せる。
- 「みんなの作品が1つの画面で泳ぐ」体験（Viscuit の水族館のような体験）を、名称や画面デザインはまねせずに、オリジナルの形で実現する。

## 2. 対象利用者と利用場面

| 利用者 | 主な使い方 |
|---|---|
| 小学生（低〜高学年） | ひらがな中心の画面で、迷路・おえかきを解く |
| 中学生 | 変数・入れ子・アルゴリズムの課題、英語モード |
| 先生・保護者 | 解答の読み込み（先生モード）、水族館の部屋作り、解説書・解説動画・解答集を使った授業の準備と説明、修了証の印刷 |
| イベント参加者 | 1台の端末を交代で使う（「つぎの ひとへ」でリセット） |

想定端末：PC（Chrome / Edge / Safari）、iPad（横 1024〜1366px、縦 744〜1024px）、電子黒板・プロジェクター。

## 4. 共通要件（全ページ）

### 4.1 画面構成
- 左にブロックを組む場所（Blockly）、右に課題パネル・盤面・メッセージを置く。
- 幅 900px 以下では、ブロックの場所（画面の高さの 60%）と盤面を縦に並べる。
- ヘッダーには、タイトル、他ページへのリンク（🐢 ⛏ 🚀 🧱 🐟 🎬 📖 のうち自分以外の6つ）、▶ じっこう、↺ もどす、📖 こたえ（先生モードのみ）、⚙ きのう を置く。
- 支援ページ（どうが・かいせつしょ）のヘッダーは、タイトル、他ページへのリンク、⚙ きのう とする。

### 4.2 デザインの統一
- ヘッダー（高さ 56px）、ボタン、パネル（幅 400px）、右列（幅 440px）、盤面の枠（400×400px＋黒枠）、メッセージ、クリアのウィンドウの形と大きさは `common.css` で全アプリ共通とする。
- 各ページは CSS 変数（`--hdr-bg` `--panel-bg` など）でテーマの色だけを決める。

| アプリ | テーマ |
|---|---|
| おえかき | 空とノート |
| めいろ | 草と土 |
| うちゅう | 宇宙 |
| こわす・おく | 石と洞くつ |
| すいぞくかん | 海 |
| かいせつ どうが | えいがかん |
| かいせつしょ | ほんだな |

- 「▶ じっこう」ボタンは全アプリ同じ緑とする。
- 文字はドットフォント（DotGothic16）に統一する。子ども向けの表示はひらがな中心とする。

### 4.3 ヘッダーの1行表示（iPad 対応）
画面幅に応じて段階的に文字を隠し、ヘッダーを常に1行に収める。

| 画面幅 | 表示 |
|---|---|
| 1441px 以上 | すべて文字付き |
| 1440px 以下 | アプリのリンクはアイコンだけ |
| 1240px 以下 | 「▶ じっこう」「⚙ きのう」以外のボタンはアイコンだけ |
| 860px 以下 | タイトルと「⚙ きのう」もアイコンだけ |

- 受け入れ基準：7ページ × 2言語 × 14通りの幅（744〜1920px）で、ヘッダーのボタン・リンクが2行にならないこと。

### 4.4 ⚙「きのう」メニュー
「音」「言語選択」「リセット」などは、ヘッダーの「⚙ きのう」（英語では「⚙ Settings」）ボタンにまとめる。押すとメニューが開く。

| メニュー項目 | 動作 | 対象アプリ |
|---|---|---|
| 🐍 Python に きりかえる | もとのアプリに対応する Python版を、Python モードで開く（めいろ → python.html、うちゅう → python-space.html、こわす・おく → python-craft.html）。メニューの先頭に、ほかの項目と色を変えて表示 | めいろ・うちゅう・こわす・おく |
| 🧩 ブロックの アプリに もどる | Python版から、もとのブロックのアプリへ戻る | Python版3つ |
| 📝 リリースノート（v〇.〇） | リリースノートのページを開く。今のバージョン番号を表示し、まだ見ていない新しいバージョンがあるときは「NEW」を付ける | リリースノート以外の全ページ |
| 🔊 おと：オン／オフ | 効果音の切り替え。メニューは開いたまま状態を表示 | めいろ・うちゅう・こわす・おく・Python版3つ |
| 🌐 English（えいご）に する | 日本語／英語の切り替え | 全アプリ |
| 🌙 ナイトモードに する | 画面全体を暗い色にする（もう一度で「☀️ ふつうの あかるさに もどす」） | 全アプリ |
| 🎨 おちついた いろに する | あざやかさとコントラストを下げる（もう一度で「🌈 もとの いろに もどす」） | 全アプリ |
| 📜 しゅうりょうしょうを みる | 修了証を表示する（全ステージクリア時のみ表示） | めいろ・うちゅう・こわす・おく・Python版3つ |
| 🔄 つぎの ひとへ | 次の人のためのリセット（2回押しで実行） | めいろ・うちゅう・こわす・おく・Python版3つ |

- ページを移る項目（🐍／🧩・📝）は上部にまとめ、設定の項目との間を少し空ける。切り替え先がないページ（おえかき・すいぞくかん・どうが・かいせつしょ・リリースノート）には 🐍／🧩 を出さない。
- メニューの外をタップするか Esc キーで閉じる。
- 項目は指で押しやすい高さ（48px 以上）とする。

### 4.5 日本語／英語の切り替え
- 画面の文字、ブロックの文字、ステージ・おだいの説明とヒント、メッセージ、ダイアログ、修了証を切り替える。
- Blockly 標準の文言（右クリックメニュー等）も、対応する言語ファイルを読み込んで切り替える（Blockly を使わない支援ページでは読み込まない）。
- 解説動画は言語に合わせて日本語版／英語版を、解説書は日本語／英語の文と解答画像を出し分ける。
- 標準ブロックの表示は日本語ではひらがなに固定する（例：「4 かい くりかえす」「i を 1 から 10 まで 1 ずつ かぞえる」）。
- 選んだ言語は端末に記憶し、全アプリで共通とする。URL の `?lang=en`／`?lang=ja` でも指定できる。
- 切り替えても、組んだブロックと進み具合は消えない。
- 英語は小学生にも読めるやさしい表現とする。

### 4.6 ナイトモード・落ち着いた色
- ナイトモード：背景・パネル・ボタン・メニューを暗い色にし、盤面と絵は明るさを約 78% に下げる。暗くしても、おえかきのお手本の線と描いた線が見えること。
- 落ち着いた色：画面全体の彩度を 45%、コントラストを 90% にする。テーマの雰囲気は残す。
- 2つは同時に使える。設定は端末に記憶し、全アプリで共通とする。ページを開いた瞬間に反映し、ちらつかないこと。
- 「つぎの ひとへ」では消えない（端末の設定として扱う）。

### 4.7 効果音
- Web Audio で 8ビット風の音をその場で合成し、音声ファイルは使わない。
- ブラウザの制限のため、最初にボタンを押したときから鳴らす。

| 場面 | 音 |
|---|---|
| 前に進む | 足音（左右で高さを変える。宇宙は「ぽよん」） |
| 右を向く／左を向く | 「ひゅっ↑」／「ひゅっ↓」（聞くだけで左右が分かる） |
| ぶつかる | 「ゴンッ」 |
| ステージクリア | 「ドミソド〜」のファンファーレ |
| 目安オーバーでゴール | 短い2音 |
| 失敗（ゴールに着かない等） | 下がる3音 |
| 全クリア | 長めのファンファーレ |
| 宇宙：星を拾う／全部集める／発射 | 「ピロン」／上がる4音／「ゴゴゴ…」 |
| こわす・おく：こわす／置く／水に落ちる／宝箱 | 「カッカッ ガラッ」／「ゴトッ」／「ポチャン」／上がる4音 |

### 4.8 実行時の表示
- 実行中は、いま動いているブロックを光らせる。
- 失敗したときは、理由と次にすることが分かるメッセージを出す（例：「💥 ぶつかっちゃった！」「❓ ここには ほしが ないよ！」）。
- 無限ループでページが固まらないように、動きの回数とくりかえしの回数に上限を設ける（上限に達したら「うごきが おおすぎるよ」「くりかえしが おわらないよ」と表示して止める）。
- 実行後に「つかった ブロック：〇こ ／ うごいた かず：〇かい」を表示する。

### 4.9 ステージクリア時の確認（めいろ・うちゅう・こわす・おく）
- クリアすると「🎉 ステージ クリア！ つぎの ステージに いきますか？」と次のステージ名を表示し、「はい」「いいえ」を出す。
  - 「はい」：次のステージへ移動する。
  - 「いいえ」：キャラクターをスタートに戻し、組んだブロックは残したまま同じステージに再挑戦できるようにする。Esc キーも「いいえ」と同じ。
- 目安のブロック数を超えたゴール、失敗、じゆうモードでは出さない。
- クリア直後に別のステージへ切り替えたときは、前のステージの確認ウィンドウを出さない。

### 4.10 「つぎの ひとへ」（リセット）
- 誤操作防止のため2回押しで実行する。1回目で項目が赤い「⚠ もういちど おすと リセット」に変わり、4秒以内にもう一度押すと実行する。
- 消すもの：全ステージで組んだブロック、クリアの ✅、ランダム迷路（世界）、修了証の名前。
- 残すもの：音、言語、ナイトモード、落ち着いた色の設定。
- 実行後はステージ1に戻り、「✨ リセットしたよ。つぎの ひと、がんばってね！」と表示する。

### 4.11 先生モード
- URL に `?sensei` を付けたときだけ「📖 こたえ」ボタンを表示する（子どもの画面には出さない）。
- 押すと、選んでいる課題の解答ブロックをワークスペースに読み込む（組んでいたブロックは置きかわる）。

### 4.12 📜 修了証（めいろ・うちゅう・こわす・おく・Python版3つ）
- じゆうモード以外の全ステージをクリアした瞬間に表示する。閉じたあとは、次のステージ（じゆうモード）への確認を出す。
- 記載内容：

| 項目 | 日本語 | 英語 |
|---|---|---|
| タイトル | 修了証（ふりがな「しゅうりょうしょう」） | Certificate of Completion |
| 名前 | 「〇〇 さん」（空欄可） | 名前のみ（空欄可） |
| 本文 | アプリ名と、がんばりをたたえる文 | 同左 |
| 日付 | 端末の日付（例：2026年11月8日） | 端末の日付（例：November 8, 2026） |
| 発行者 | 舞鶴工業高等専門学校　井上泰仁 | National Institute of Technology (KOSEN), Maizuru College / Yasuhito Inoue |

- 名前はその場で入力し、修了証にすぐ反映する。名前は保存しない（共用端末への配慮）。
- 「🖨 いんさつ」で A4 横 1枚に印刷し、「💾 がぞうで ほぞん」で PNG 画像として保存する。
- 「⚙ きのう」メニューから何度でも再表示できる。
- 四隅にアプリごとのアイコンを入れる（めいろ ⛏💎、うちゅう 🚀⭐、こわす・おく 🧱⛏、Python版 めいろ 🐍💎・うちゅう 🐍⭐・こわす・おく 🐍🧱）。

### 4.13 📝 リリースノート（releases.html）
- これまでの変更をバージョンごとにまとめ、新しいものを上に表示する。日本語・英語に対応する。
- 各バージョンに、番号・日付（記録のあるもの）・変更の一覧を表示する。変更には種類のラベルを付ける：ついか（New）／かいぜん（Improved）／しゅうせい（Fixed）／しりょう（Docs）。
- 最新のバージョンに「NEW」を付ける。
- 現在のバージョン番号は `i18n.js` の `RELEASE_VERSION` に置く。端末で一度リリースノートを開くと `block-release-seen` に記録し、メニューの「NEW」を消す。新しいバージョンを出すときは、`releases.html` の `RELEASES` の先頭に1件足し、`RELEASE_VERSION` を同じ番号にする。

### 5.6 🐍 Python版（python.html ／ python-space.html ／ python-craft.html）
- めいろ（5.2）・うちゅう（5.3）・こわす・おく（5.4）のそれぞれに Python版を置き、プログラムを Python で表す。ブロックから文字のプログラミングへ進むための橋渡しとする。
- **しくみ**：3つのページは共通部品 `python-core.js` を使う。各ページは、もとのアプリの「せかい（マップ）・判定（simulate）・ドット絵・効果音」をそのまま使い、命令の対応・しらべる関数・ステージだけを定める。
  - Python のコードは、ページ内の小さな解釈器で読み取り、決まった命令だけの JavaScript（`forward();` など。各行に行番号の目印を付ける）に変換して、もとのアプリと同じ `simulate` で動かす。子どもが書いた文字をそのまま `eval` しない。
  - そのため、ぶつかる・水に落ちる・ほしがない などの判定とメッセージは、ブロックのアプリと同じになる。
- **2つのモード**（左上のタブで切り替え。最後に使ったモードを覚える）：

| モード | 画面 | 動作 |
|---|---|---|
| 🧩 ブロック（はじめはこちら） | 上：Blockly、下：「Python で かくと こうなるよ」（見るだけ） | ブロックを動かすたびに、同じ動きの Python のコードを下に表示する |
| 🐍 Python | コードエディタ＋命令ボタン | 自分で Python を書いて実行する |

- **ブロック ⇄ Python の変換**
  - ブロック → Python：ブロック1つが Python の1行になる。「そうでなければ」の中が「もし」1つだけのときは `elif` にまとめる。中が空のくりかえし・もしは `pass` にする。
  - Python → ブロック：書いたコードを読み取ってブロックを組み直す。`#` のコメントはブロックにないため消える（そのことを表示する）。
  - 文法エラーがあるとき、またはブロックにできない書き方（`while True:`、`while is_open(...)`、`if not ...`、`if at_goal()` など）のときは、行番号を示して Python モードのままにする。
  - いちばん上のかたまりだけを実行し、離れたブロックがあるときは知らせる。
- **ブロックと Python の対応**（画面の「🧩 ブロックと 🐍 Python の たいおう」に表で示す。ブロックの文字と色は もとのアプリと同じ）：

| ブロック | Python | アプリ |
|---|---|---|
| まえに すすむ ／ みぎを むく ／ ひだりを むく | `forward()` ／ `turn_right()` ／ `turn_left()` | 3つとも |
| ⭐ ほしを ひろう | `pick_up()` | うちゅう |
| ⛏ まえの ブロックを こわす ／ 🧱 まえに ブロックを おく | `mine()` ／ `place()` | こわす・おく |
| 〇かい くりかえす | `for i in range(〇):`（〇は 1〜50） | 3つとも |
| ゴールに つくまで くりかえす | `while not at_goal():` | めいろ・こわす・おく |
| 🚀 ミッション クリアまで くりかえす | `while not mission_done():` | うちゅう |
| もし （まえ／みぎ／ひだり）が あいていたら | `if is_open('front'):`（`'right'`／`'left'`） | めいろ・うちゅう |
| もし ここに ⭐ ほしが あったら | `if has_star():` | うちゅう |
| もし まえが （いしブロック／みず／すすめる みち） だったら | `if front_is('stone'):`（`'water'`／`'path'`） | こわす・おく |
| そうでなければ | `else:`（中が「もし」だけなら `elif ...:`） | 3つとも |

- 「もし」の各ブロックには、「そうでなければ」付きの形も用意する（Python で `else` や `elif` を書いたときにブロックへ戻せるようにする）。
- **使える Python**：上表の命令に加えて `pass`、`while True:`、`not`、`#` コメント。字下げはスペース4つ（Tab キーでスペース4つを入れる）。
- **ステージ**（ステージの盤面は もとのアプリと同じ。ランダム・じゆうモードは置かない）：

| アプリ | # | タイトル | 学ぶこと |
|---|---|---|---|
| めいろ | 1〜5 | まっすぐ すすもう／まがってみよう／for で くりかえそう／while と if／elif で 3つに わけよう | 順次、`()`、`for` とコロン・字下げ、`while not`・`if`／`else`、`elif` |
| うちゅう | 1〜6 | ほしを ひろおう／まがって あつめよう／for で あつめよう／ほしの かいだん／`if has_star():`／`while not mission_done():` | `pick_up()`、順次、`for` の中に2行以上、パターン、入れ子の字下げ（8つ）、`while not` と2つの `if` |
| こわす・おく | 1〜7 | こわして すすもう／はしを かけよう／for で こわそう／ながい はし／`if front_is('stone'):`／elif で いしと みず／うずまきの どうくつ | `mine()`・`place()`、持っている数、`for`、`if front_is(...)`、`elif`、`if`・`elif`・`elif`・`else` の4分岐 |

- 使えるブロックはステージごとに増やす（もとのアプリと同じ順）。
- **実行**：コードを読み取ってから動かす。動いている行を黄色で光らせ、ブロックモードでは対応するブロックも光らせる。上限は もとのアプリと同じ（めいろ：動き 200回、うちゅう：400回、こわす・おく：300回）。クリア時は もとのアプリと同じ演出（うちゅう：ロケット発射、こわす・おく：たからばこが開く）。
- **エラー表示**：本物の Python と同じエラー名に、ひらがなの説明と行番号をつける。エラーの行は赤く光らせ、下のコンソールにも `File "main.py", 〇ぎょうめ` の形で表示する。

| 原因 | 表示（例） |
|---|---|
| 行末の `:` 忘れ | SyntaxError：さいごに「:」（コロン）が ひつようだよ |
| 字下げのずれ | IndentationError：じさげ（あたまの スペース）が そろっていないよ |
| `:` の次の行を字下げしていない | IndentationError：「:」の つぎの ぎょうは、スペース 4つ じさげ しよう |
| `()` 忘れ | SyntaxError：「forward」の あとに「()」を つけよう |
| ない命令 | NameError：「jump」という めいれいは ないよ |
| `if` のない `else`／`elif` | SyntaxError：「else」「elif」の まえには「if」が ひつようだよ |
| `()` の中の言葉が違う | ValueError：「is_open()」の () の なかは 'front' 'right' 'left' の どれかだよ |
| 命令の `()` に何か書いた | TypeError：「forward()」の () の なかには なにも かかないよ |
| しらべる関数だけを書いた | 「is_open()」は しらべる ための もの。if や while と いっしょに つかおう |
| `range()` の数が 1〜50 以外 | ValueError：range() の かずは 1〜50 に しよう |
| 実行中の失敗 | もとのアプリと同じメッセージ（例：💥 ぶつかっちゃった！、💦 みずに おちちゃった！、❓ ここには ほしが ないよ！）に、止まった行番号を付ける |
| 最後まで動いたがクリアしない | もとのアプリと同じメッセージ（例：ゴールに つかなかったよ、ほしが あと 〇こ のこっているよ） |

- **エディタ**：行番号、色分け（キーワード・命令・数・文字・コメント）、Enter で字下げを引き継ぐ（`:` の後は4つ増やす）、Backspace で字下げを4つずつ戻す、命令ボタン（押すと今の字下げに合わせて1行入る）。
- クリア時の「つぎの ステージに いきますか？」（4.9）、修了証（4.12）、「つぎの ひとへ」（4.10）、「こたえ」ボタン（先生モード `?sensei` のときだけ表示）は もとのアプリと同じ。
- 「⚙ Python に きりかえる」で開いたときは Python モードで開く（URL に `?mode=python` を付け、開いたあとは URL から消す）。ふつうに開いたときは、最後に使ったモードで開く（はじめはブロック）。
- 見た目（ヘッダー・パネル・盤面の色）は もとのアプリのテーマを使い、タイトルのアイコンを 🐍 にする。

### 5.5 🐟 おさかな すいぞくかん（aquarium.html）

**流れ**

**ブロック**

- 〇 びょう まつ、はやさを 〇 にする（1〜10）、おおきさを 〇 % にする（30〜300）
- 〇 かい くりかえす、数、ランダムな数

**水族館の画面**
- URL：`?view=tank&room=部屋番号`
- 内容：水のグラデーション、光のすじ、砂、揺れる海藻、泡。魚は左向きでもさかさまにならない。

- 全画面表示ボタンを付ける。

**モード**

| モード | 条件 | 内容 |
|---|---|---|
| ローカルモード | `firebase-config.js` が空 | 1台の端末で遊ぶ（別タブの水族館に反映） |
| Firebase モード | 設定あり | クラス全員の魚がリアルタイムで先生の画面に集まる |

**制限**

**安全**

## 7. 非機能要件

### 7.1 動作環境
- 最新の Chrome／Edge／Safari（iPad 含む）で動くこと。
- サーバー側の処理は不要とする（GitHub Pages の静的配信のみ）。Firebase は任意とする。
- `file://` で直接開いた場合は、ローカルモード以外の Firebase 機能は動かない（`https://` で開く）。

### 7.2 使いやすさ・アクセシビリティ
- 子ども向けの表示はひらがな中心とし、英語はやさしい表現とする。
- 失敗メッセージは、次の行動が分かる表現とする。
- 重要な操作（リセット、全削除）は2回押しで確認する。
- 音の消音、ナイトモード、落ち着いた色を選べるようにする。
- タッチ操作で使えること（メニュー項目 48px 以上、ドット絵エディタはポインタ操作対応）。

### 7.3 安全・プライバシー
- 子どもの名前・個人情報は保存しない（修了証の名前も保存しない）。
- Firebase では匿名認証を使い、データベースのルールで書き込みを制限する（9章）。
- Firebase の API キーは公開してよい値とし、安全はルールで守る。

### 7.4 保守性
- 共通部品は `common.css`／`i18n.js`／`certificate.js` に集約する。
- 新しいアプリは、共通ファイルを読み込み、テーマの色（CSS 変数）を決めるだけで見た目がそろうようにする。
- ページ間のリンクは `i18n.js` の一覧に1行足すだけで、全ページのヘッダーに反映されるようにする。
- 解説書のデータ（`guide-data.js`）と解説動画は、アプリのステージ定義と解答データから作る。ステージを変えたときは作り直す。
- おだい・ステージは配列（`CHALLENGES`／`LEVELS`）に追加するだけで増やせるようにする。
- ソースコードのコメントはひらがな中心で、中学生でも読めるようにする。

### 7.5 著作権・名称
- Blockly（Apache License 2.0）を使う。
- マインクラフト、Viscuit などの名称・キャラクター・画面デザイン・ロゴは使わない。作品名や README にもその名称を出さない。
- ドット絵・効果音・キャラクターはすべてオリジナルとする。

## 9. Firebase 連携の仕様（すいぞくかん）

### 9.1 データ構造（Realtime Database）

```
rooms/
  {部屋番号 5文字}/
    owner:     作った先生の匿名 uid
    createdAt: 作成時刻（サーバー時刻）
    fish/
      {自動ID}/
        px:   ドット絵（16進 256文字）
        prog: 泳ぎ方（ブロックの JSON、8000文字まで）
        by:   入れた人の匿名 uid
        t:    サーバー時刻
```

### 9.2 権限（database.rules.json）

| 操作 | 許可する人 |
|---|---|
| 部屋を作る | 匿名ログインした人（作った人が先生になる） |
| 魚を入れる | 部屋が存在するとき、匿名ログインした人 |
| 魚を見る | 部屋番号を知っている人 |
| 魚を消す | その部屋の先生、または入れた本人 |
| 全部消す | その部屋の先生 |
| 他人の魚を書きかえる | だれもできない |
| 決められた項目以外のデータ | 受け付けない |

### 9.3 運用上の注意
- 無料プラン（Spark）は同時接続 100 まで（1クラスなら十分）。
- 魚を消せるのは、部屋を作ったのと同じブラウザだけ。部屋作りと水族館の表示は同じ PC で行う。
- ロケーションはシンガポール（asia-southeast1）を推奨する。

### 自動テストで確認済みの事項
- 全アプリ・全課題の解答が、日本語・英語の両方でクリアできること。
- めいろステージ8の右手法はランダム迷路 900 個、うちゅうステージ7の解答はランダムな宇宙 1,000 個以上で全クリアできること。
- 失敗パターン（ぶつかる、拾えない、こわせない、無限ループ等）で正しいメッセージが出ること。
- ヘッダーが 9ページ × 2言語 × 14通りの画面幅で1行に収まること。
- Python版3つ（めいろ 5・うちゅう 6・こわす・おく 7 ステージ）の解答が、ブロックモード・Python モードの両方、日本語・英語でクリアできること。ブロックで組んだ解答から作った Python が、解答コードと一字一句同じになること。ブロック→Python→ブロックの変換で内容が変わらないこと（else の中が「もし」1つのときは elif になる）。エラー（コロン忘れ・字下げ・「()」忘れ・ない命令・if のない else・`()` の中の言葉違い・range の範囲外）と、ぶつかる・水に落ちる・ほしがない・こわせない・おけない・動きすぎで、正しい行番号とメッセージが出ること。ブロックにできない書き方（while True、if not など）は Python のまま残ること。全ステージクリアで修了証が出ること。
- めいろ・うちゅう・こわす・おく の「⚙ きのう」の先頭に「🐍 Python に きりかえる」が出て、対応する Python版が Python モードで開くこと。Python版3つでは「🧩 ブロックの アプリに もどる」でもとのアプリに戻ること。ほかのページには出ないこと。
- 全ページの「⚙ きのう」メニューに 📝 リリースノート（v1.7）が出て、未読のときだけ「NEW」が付き、リリースノートを開くと消えること。リリースノートのページに 16 のバージョンが日本語・英語で表示されること。
- 修了証が全ステージクリア時のみ表示され、A4 横 1枚で印刷できること。
- すいぞくかんの部屋作り→送信→表示→削除の流れ（代替 Firebase）、および不正データへの耐性。
- 解説動画 80本（Python版 36本を含む）がすべて同じ形式（H.264 1280×720 30fps＋AAC）で、字幕 152 か所がすべて帯に収まること（最小 22px）。一覧ページで 44本すべてが読み込めること。
- 解説書で 49課題すべての解答画像（Python版は解答コード）・動画・アプリへのリンクが存在し、ページ内リンク（もくじ・学びのつながり表）がすべて移動先を持つこと。日本語・英語で表示できること。
