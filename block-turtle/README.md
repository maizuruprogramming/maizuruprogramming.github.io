# 🐢 ブロックでおえかき

小・中学生向けのブロックプログラミングアプリです。ブロックを組み合わせてカメを動かし、絵をかきます。

- [Blockly](https://developers.google.com/blockly)（Google製、Apache License 2.0）を使っています
- ファイルは `index.html` の1つだけです。インストールやビルドは要りません

## つかいかた

1. 左のカテゴリからブロックをドラッグして、つなげます
2. 「▶ じっこう」をおすと、カメが絵をかきます
3. 「🧽 けす」で、かいた絵をけします

組んだブロックはブラウザに自動で保存されるので、次に開いたときも残っています。

## おだい（課題）モード

右上のリストから「おだい」を選ぶと、お手本がうすい灰色で表示されます。
お手本と同じ形をかけたら「🎉 せいかい！」と表示されます。
おだいは★1〜★5の9問です。こたえと学べる内容は [ANSWERS.md](ANSWERS.md) にまとめています。URL に `?sensei` を付けて開くと「📖 こたえ」ボタンが出て、解答ブロックを読み込めます。

## 🤖 ブロックでめいろ（maze.html）

5×5 マスのめいろで、ロボットを左上のスタートから右下のゴール 🚩 まで動かします。いわ（障害物）はランダムに置かれますが、かならずゴールまで行けるようになっています。

- 使うブロック：「まえに すすむ」「みぎ／ひだりを むく」「〇回 くりかえす」「ゴールに つくまで くりかえす」「もし まえ／みぎ／ひだり が あいていたら（そうでなければ）」
- 実行中は、いま動いているブロックが光ります
- 効果音が鳴ります（すすむ・右／左を向く・ぶつかる・ステージクリア・ざんねん・チュートリアル全クリア）。消音は「⚙ きのう」メニューの「🔊 おと」でできます
- 次の人に交代するときは、「⚙ きのう」メニューの「🔄 つぎの ひとへ」を2回押します。全ステージのブロック・クリアの✅・ランダム迷路が消えて、ステージ1に戻ります（音の設定は残ります）
- いわにぶつかったり、ゴールに着かなかったりしたら、メッセージが出ます
- 「🎲 あたらしい めいろ」をおしても、組んだプログラムは消えません

### チュートリアル（全8ステージ＋じゆうモード）

上のリストからステージを選びます。クリアしたステージには ✅ がつきます。
クリアすると「つぎの ステージに いきますか？」と出ます。「はい」で次のステージへ進み、「いいえ」で同じステージにもう一度挑戦できます（組んだブロックは残ります）。ステージごとに使えるブロックが増えていきます。

| ステージ | 学ぶこと | 使えるブロック | めやすのブロック数 | こたえの例 |
|---|---|---|---|---|
| 1 まっすぐ すすもう | 順番に並べる（順次） | すすむ | – | すすむ ×4 |
| 2 まがってみよう | 向きの考え方 | ＋むく | – | すすむ×2 → みぎ → すすむ×2 |
| 3 ながい みち | 長い手順を組み立てる | 同上 | – | すすむ×4 → みぎ → すすむ×2 → みぎ → すすむ×4 |
| 4 くりかえしを つかおう | くりかえし | ＋〇回くりかえす | 5 | くりかえす4（すすむ）→ みぎ → くりかえす4（すすむ） |
| 5 かいだんを のぼろう | パターンを見つける | 同上 | 5 | くりかえす4（すすむ・みぎ・すすむ・ひだり） |
| 6 もし〜なら | 条件分岐、条件つきのくりかえし | ＋ゴールまで・もし | 4 | ゴールまで（もし まえ→すすむ／でなければ→みぎ） |
| 7 みぎ？ ひだり？ | 条件分岐の入れ子 | 同上 | 6 | ゴールまで（もし まえ→すすむ／でなければ もし みぎ→みぎ／でなければ→ひだり） |
| 8 どんな めいろでも | 一般化（アルゴリズム） | すべて | – | 下の「右手法」 |

- ステージ4〜7は、目安のブロック数をこえてもゴールはできます。そのときは「〇こ いかに できるかな？」とうながします
- ステージ8は、表示中のめいろでゴールしたあと、ランダムなめいろ30個で自動テストします。全部ゴールできたらクリアです
- 組んだプログラムはステージごとにブラウザに保存されます

各ステージの解答は [ANSWERS.md](ANSWERS.md) にあります。URL に `?sensei` を付けて開くと「📖 こたえ」ボタンが出て、解答ブロックを読み込めます。

ステージ8の答えの一例は「右手法」です。右手を壁につけたまま進む考え方です。

```
ゴールに つくまで くりかえす
  もし みぎ が あいていたら
    みぎを むく
    まえに すすむ
  そうでなければ
    もし まえ が あいていたら
      まえに すすむ
    そうでなければ
      ひだりを むく
```

## ⛏ めいろの なかま（maze-junior.html ／ maze-key.html ／ maze-enemy.html）

「ブロックでめいろ」と同じ見た目・操作の、べつバージョンの めいろです。めいろの ページ（Python版も）の「⚙ きのう」→「⛏ めいろを えらぶ…」で表が開き、4種類 × ブロック／Python の8つから選べます（いま開いているところと、クリアしたステージの数も出ます）。

| アプリ | 学ぶこと | ステージ | 新しいブロック |
|---|---|---|---|
| 🧭 やじるしの めいろ（低学年向け） | 順番 | 6（4×4・5×5） | うえへ ⬆／したへ ⬇／ひだりへ ⬅／みぎへ ➡（むきを考えずに1マス） |
| 🗝 かぎと とびらの めいろ | 状態（持っている物を覚えておく） | 4 | かぎを ひろう／とびらを あける／もし［まえが とびら・ここに かぎが ある］なら |

- かぎ1つで、とびらが1つ開きます。持っているかぎの数は盤面の上に出ます（てき の めいろは ターン数）。
- スライムは、たんけんかが1回動く（すすむ・むく・まつ）たびに1マス動き、端で引き返します（ランダムではないので先が読めます）。通り道は紫の点で表示します。

- 3つのページは `maze.html` をもとに `tools/maze-variants/build.py` で作っています。ページを直すときは `tools/maze-variants/` の中の key.js・enemy.js・junior.js を直して、作り直してください。

## 🚀 うちゅうで ほしあつめ（space.html）

「ブロックでめいろ」の宇宙・アイテムあつめ版です。宇宙飛行士を動かして星 ⭐ を全部拾い、ロケット 🚀 に乗り込むとロケットが発射します。

- 新しいブロック：「⭐ ほしを ひろう」「もし ここに ほしが あったら」「🚀 ミッション クリアまで くりかえす」
- 星のないマスで拾おうとすると失敗します。「その場で調べてから行動する」（条件分岐）を自然に学べます
- 全7ステージ＋じゆうモードです。ステージ7は、ランダムな宇宙30個で自動テストします
- 効果音、クリア時の「はい／いいえ」、「⚙ きのう」メニュー、先生モード（`?sensei`）は迷路と同じです。進み具合は迷路とは別に保存されます
- 解答は [ANSWERS.md](ANSWERS.md) にあります

## 🧱 こわして つくる ぼうけん（craft.html）

「ブロックでめいろ」の、こわす・おく版（マイクラ風）です。つるはしで石ブロックをこわすと、そのブロックが持ち物に入ります。水の上にブロックを置くと、橋になって渡れます。たからばこに着くとクリアです。

- 新しいブロック：「⛏ まえの ブロックを こわす」「🧱 まえに ブロックを おく」「もし まえが ［いしブロック／みず／すすめる みち］ だったら」
- 「もっている ブロック：〇こ」が表示されます。こわすと増え、置くと減ります。持っている数を考えて順番を組み立てることを学べます
- かたい岩（こわせない）、石（こわせる）、水（橋をかける）の3種類の障害物があります
- 全7ステージ＋じゆうモード（ランダムな世界）です
- 効果音（カッカッ・ゴトッ・ポチャン・たからばこの音）、クリア時の「はい／いいえ」、「⚙ きのう」メニュー、先生モード、日本語／英語は、ほかのアプリと同じです
- 解答は [ANSWERS.md](ANSWERS.md) にあります（日本語・英語）

## 🐍 Python版（python-draw.html ／ python.html ／ python-space.html ／ python-craft.html ／ python-maze-*.html）

おえかき・めいろ・うちゅう・こわす・おく と、めいろの なかま3つに、それぞれ **Python版** があります。ブロックで組むと、おなじ動きの Python のコードが下に出ます。「🐍 Python」タブに切りかえると、自分で Python を書いて動かせます。ブロックから文字のプログラミングへ進むためのページです。

| ブロック | Python |
|---|---|
| まえに すすむ ／ みぎを むく ／ ひだりを むく | `forward()` ／ `turn_right()` ／ `turn_left()` |
| 〇かい くりかえす | `for i in range(〇):` |
| ゴールに つくまで くりかえす（うちゅうは ミッション クリアまで） | `while not at_goal():`（`while not mission_done():`） |

- ステージを全部クリアすると修了証が出ます。動いている行（とブロック）が光ります。

- Python はページの中の小さな解釈器で読み取り、決まった命令だけの JavaScript に直して動かします（外部ライブラリなし、子どもが書いた文字を `eval` しない）。使えるのは各アプリの命令と `for`／`while`／`if`／`elif`／`else`／`not`／`pass` です。
- Python からブロックにもどすとき、ブロックにできない書き方（`while True:` など）はそのまま Python で使います。
- 先生モード（`?sensei`）では「📖 こたえ」ボタンで解答コードを読み込めます。
- おえかきの Python版は、`()` の中に数・変数・計算（`+ - * / // % **`）を書けます。`range(はじめ, おわり, ふやす かず)` の「おわり」は含まれません（ブロックの「i を 10 から 200 まで 10 ずつ」＝ `range(10, 201, 10)`）。お手本との一致の判定は、ブロックのおえかきと同じです。
- 7つのページは、共通部品 `python-core.js`（解釈器・エディタ・ブロック ⇄ Python）と `python.css` を使います。

- 子どもに見せる画面はひらがな中心です。めあて・声かけの例・つまずきやすいところ・解説動画のファイル名は、各スライドの**ノート欄**にあります。
- 「こたえ」のスライドは、子どもが挑戦したあとに見せてください。

## 📝 リリースノート（releases.html）

「⚙ きのう」→「📝 リリースノート」で、これまでの変更をバージョンごとに見られます（新しいものが上）。新しいバージョンが出ると、メニューの項目に「NEW」が付きます（一度開くと消えます）。

新しいバージョンを出すときは、次の2か所をそろえます。

1. `releases.html` の `RELEASES` のいちばん上に1件足す（`v`・`date`・`items`）
2. `i18n.js` の `RELEASE_VERSION` を同じ番号にする

## 🐟 おさかな すいぞくかん（aquarium.html）

子どもがドット絵で描いた魚を、ブロックで決めた泳ぎ方で動かします。みんなの魚が、先生の大きな画面の水族館で一緒に泳ぎます。

- **① 描く**：16×16 マスのドット絵（15色＋けしゴム、左右反転、お手本）
- **② 泳ぎ方を決める**：すすむ・まわる・ランダムに向きを変える・かべではねかえる・まつ・はやさ・おおきさ・くりかえし・ランダムな数
- **③ 水族館に入れる**：へやの番号を入れて送ると、先生の画面に「あたらしい なかまが きたよ！」と魚が現れます

| モード | 使い方 |
|---|---|
| ローカルモード（設定なし） | 1台の端末で遊ぶ。`aquarium.html?view=tank` を別のタブで開くと、その端末で入れた魚が泳ぐ |
| Firebase モード | クラス全員の魚が、先生の画面にリアルタイムで集まる。設定は [FIREBASE_SETUP.md](FIREBASE_SETUP.md) を見てください |

先生は `aquarium.html?sensei` を開いて、へやを作ります。

## 🌐 日本語 ／ English

どのアプリも、「⚙ きのう」メニューの「🌐 English（えいご）に する」で英語に切り替えられます。英語のときは「⚙ Settings」→「🌐 日本語 (Japanese)」で戻ります。
- 画面の文字、ブロックの文字、ステージの説明・ヒント、メッセージが切り替わります
- 選んだ言語は記憶され、4つのアプリで共通です。組んだブロックや進み具合はそのまま残ります
- URL に `?lang=en`（または `?lang=ja`）を付けて開くと、その言語で始まります
- [ANSWERS.md](ANSWERS.md) は、日本語の解答と英語の解答（英語のブロックの画像付き）を1つにまとめています

### 📱 スマホ（幅 600px 以下）

スマホでは、自動でスマホ向けの並びになります（PC・iPad の見た目は変わりません）。

- 上から ステージ → 盤面 → プログラム。画面のいちばん下に ブロックの棚 と「▶ じっこう」。
- ブロックは **タップで足す**。棚のブロックをタップすると、プログラムのさいごに付きます。「くりかえす」などを足すと、次からはその中に入ります（「＋ ここに いれる／つける」で場所を変えられます）。▲で上へ、×で消す。
- かずは入力欄、向きや色はリストで直せます。
- 保存は PC と同じなので、PC とスマホで続きから遊べます。
- Python版の Python タブでは「→| さげる」「|← あげる」で字下げできます。
- おさかな すいぞくかん は、まだスマホの配置にはなりません。

## 🎨 デザインの そろえかた

ヘッダー・ボタン・パネル・盤面のわく・メッセージ・クリアのウィンドウの形と大きさは、`common.css` で5つのアプリ共通にしています。
各ページの `<style>` では、テーマの色だけを変えています（`:root` の `--hdr-bg` `--panel-bg` などの変数）。
「▶ じっこう」ボタンは、どのアプリも同じ緑です。

| アプリ | テーマ |
|---|---|
| 🐢 おえかき | 空とノート |
| ⛏ めいろ | 草と土 |
| 🚀 うちゅう | 宇宙 |
| 🧱 こわす・おく | 石と洞くつ |
| 🐟 すいぞくかん | 海 |

新しいアプリを足すときは、`common.css` を読み込んで、`:root` で色を決めるだけでそろいます。

## GitHub Pages で公開する

1. GitHub で新しいリポジトリを作り、上のファイルを `images` フォルダごとアップロードします
2. リポジトリの **Settings → Pages** を開きます
3. **Source** を「Deploy from a branch」、**Branch** を `main` と `/ (root)` にして **Save** をおします
4. 数分たつと `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けるようになります

## ブロックを増やすには

`index.html` の中の次の3か所に書き足します。

1. `defineBlocksWithJsonArray` … ブロックの見た目（文字や入力欄）
2. `gen.forBlock[...]` … ブロックを JavaScript に変換するルール
3. `toolbox` … ツールボックスにブロックを並べる

ブロックの見た目は [Blockly Developer Tools](https://google.github.io/blockly-samples/examples/developer-tools/index.html) を使うと、画面上でデザインできます。
