## 使い方

1. `index.html` をブラウザ(Chrome、Safari、Edge)で開きます。
2. 矢印カードをタップして並べ、「▶ うごかす」でキャラクターをゴールまで動かします。
3. 遊び方や学び方は「⚙ きのう」→「📖 あそびかた・べんきょうの しかた」で読めます(大人向けの説明もあります)。
   「⚙ きのう」→「🎓 チュートリアルしゅう」では、画面を光らせながら自動で操作して見せる見本が11本見られます(めいろ6本:はじめてのプログラム/まちがいをなおそう/くりかえし×かず/「もし」カード/くりかえしブロック/べんりなせってい、ほかの あそび5本:ドットえ/データとAI/つくって あそぶ/おんがく/からだ)。クリア記録には残りません。「📖 あそびかた・べんきょうの しかた」には、ほかの あそび と せんせいモードの説明のタブもあります。
4. 世界は「もり」「うちゅう」「ブロック」「すいぞくかん」「きょうとし」「まいづるし」「あかれんがパーク」「あらしやま」「きよみずでら」「いね・あまのはしだて」「うじ」「さっぽろ」「とうきょう」「おおさか」「おおさか ばんぱく」「こうべ」「パリ」「ロンドン」「バルセロナ」「ベルリン」「モロッコ」「シャンハイ」「ホンコン」「シンガポール」「バンコク」「カンボジア」「ニューヨーク」「シドニー」「NZみなみじま」の29から選べます。画面左上の「せかい」ボタンを押すと、ふしぎなせかい・きょうとふ・にほんのまち・ヨーロッパ/アフリカ・アジア・アメリカ/オセアニアに分けた一覧が出ます。あかれんがパーク・あらしやま・きよみずでら・いね・あまのはしだては、その場所を題材にした専用ステージ(⭐)です。
   吹き出しの下の「ばんの みかた」に、そのステージに出てくる絵の名前と役わりが出ます。ステージ名の横の色つきチップ(と番号ボタンの下線の色)は、学ぶこと(じゅんばん・くりかえし・もし・くりかえしブロック)を表します。
5. 「⚙ きのう」→「プログラムの かたち」で、絵カードと「ブロック」(Blockly風。ブロックを縦につなげる)を切り替えられます。URLの最後に `?mode=block` を付けると、最初からブロックで開きます。
   「Blockly」を選ぶと、Google Blockly のエディタ(ブロックをドラッグしてつなげる)で作れます。URLは `?mode=blockly`。Blockly は `blockly` フォルダ → なければインターネットから読み込みます(詳しくは blockly/README.txt)。
   「⚙ きのう」メニューで、学年(低学年/高学年)、ナイトモード、色覚サポートモード、目に優しいモード、文字の形(よみやすい〈標準〉/まるもじ/コンピュータ)、マスの番号(標準オン)、あしあとプレビュー(標準オフ)、言語(日本語/English)を切り替えます。
6. 画面上部の「あそびかた」タブで、めいろ のほかに次の活動を選べます(URLの最後に `?act=dot` `?act=ai` `?act=create` を付けると最初から開きます)。
   - 🎨 ドットえ: 通ったマスに色がぬれます。めいろと同じ画面・同じカードで、🔁 くりかえしを使ってお手本と同じ絵をかきます(8ステージ+じゆう)。
   - 🤖 データとAI: りんご と みかん を、自分で作ったルールと、例を見せて教えたAIで分けてくらべます。例がかたよるとAIもまちがえることを体験します。
   - 🛠 つくって あそぶ: さわると返事をするクイズを作り、遊んでもらい、選ばれた答えのグラフを見て直します。「とどける」に出るQRコードをタブレットのカメラで読み取ると、友だちも同じクイズで遊べます(リンクのコピーもできます)。
   - 🎵 おんがく:「おとのカードで おんがくプログラミング」。音のカードを並べてメロディを作り、「くりかえし」で伴奏をのせます(しょうがくせい/中学生モード)。URLは `?act=music`。英語表示・色覚サポートモードにも対応し、おんがくだけを使う場合は music.html を開きます(`music.html?lang=en&cb=1` で英語・色覚サポート)。音が出るので音量に気をつけてください。
   - 🕺 からだ:動きのカード(てを たたく・あしぶみ・ジャンプ・まわる・キック)を並べて ▶ を押すと、カードの順に笛が鳴り、画面の人形と同じ動きをみんなでします。🔁 くりかえし、「ふえ だけ」モード、ふえクイズ、じぶんのダンスがあります。URLは `?act=body`。体を動かせる広さを確保してください。
7. 先生・保護者の方は「⚙ きのう」→「🎓 せんせいモード」で、答えの表示、進み具合の一覧、設定のロックができます(入るときに簡単なかけ算の確認があります)。「📝 こたえ」タブは、いま開いている活動(めいろ・ドットえ・からだ・データとAI・つくって あそぶ・おんがく)に合わせた答えを表示し、「📊 すすみぐあい」ではドットえ・からだ の星も見られます。「📚 きょうざい」タブから、6つの活動それぞれの学習指導案・解説動画・スライド・ワークシートを開けます(教材フォルダを index.html と同じ場所に置いてください)。
   ドットえ・データとAI・つくって あそぶ も、言語を English にすると英語で表示されます。
8. アプリの詳しい情報は「⚙ きのう」→「ℹ️ この アプリに ついて」にあります。
9. 次の人に交代するときは、「⚙ きのう」→「つぎの ひとへ」でクリア記録と名前を消します。

## 注意

- インターネットにつながっていなくても、すべての機能が使えます(外部のライブラリは使わず、QRコードを作る小さなプログラム〈QRCode for JavaScript、MITライセンス〉をページに内蔵しています)。
- 「つくって あそぶ」のQRコードは、開いているページのアドレスを使います。友だちが読み取って遊ぶには、Webに公開したページ(例: GitHub Pages)から開いてください。オンラインのときは見やすいWebフォントで表示し、オフラインのときは端末の文字か、ページに内蔵した文字で表示します。
- クリア記録と名前は、開いたブラウザの中にだけ保存されます。
- 修了証の「がぞうで ほぞん」「いんさつよう PDF」は、このファイルを直接開いた場合もそのまま保存できます。
