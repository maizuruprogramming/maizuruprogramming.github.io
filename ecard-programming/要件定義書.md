# えカードで プログラミング 要件定義書

2026年11月14日

## 1. 概要

小学生が「絵カードを並べる」だけで、プログラミングの基礎である「順次」と「反復」を体験的に学べるブラウザ教材を作る。キーボード入力は不要で、画面はひらがな中心とする。

| 項目 | 内容 |
| --- | --- |
| システム名 | えカードで プログラミング(英語名: Picture Card Coding) |
| 対象 | 小学生(低学年から操作可能なこと) |
| 利用場面 | 学校の授業、体験会・イベントなど、1台を複数人で順番に使う場面 |
| 学習目標 | 命令を順番に並べる、障害物を避ける、複数の目標を回る、繰り返しで命令を短くする、条件分岐で状況に応じて動きを変える(高学年) |
| 現状 | 試作版(ブラウザで動く1ページのWebアプリ)を公開済み |

設計の基本方針は次の4つとする。

- 文字入力をなくし、タップとドラッグだけで操作できる
- 実行結果がすぐに目に見える
- 失敗しても「エラー」という言葉を使わず、楽しくやり直せる
- 1ステージを数分でクリアでき、小さな成功を積み重ねられる

## 2. 学習設計(ステージ構成)

低学年モードは全5ステージで、ステージ1〜3で「順次」、ステージ4〜5で「反復」を学ぶ。盤面は横6マス×縦5マス。各ステージに最少カード枚数を定め、その枚数以内でクリアすると星3つ、それ以外は星2つとする。

| ステージ | 名前 | 学ぶこと | カード上限 | 星3つの条件 |
| --- | --- | --- | --- | --- |
| 1 | まっすぐ すすもう | 命令を順番に並べる | なし | 4枚以内 |
| 2 | まがって すすもう | 方向を変えて障害物を避ける | なし | 7枚以内 |
| 3 | ぜんぶ あつめよう | 複数の目標を順に回る | なし | 6枚以内 |
| 4 | くりかえしの まほう | 同じ命令を繰り返す(反復の導入) | 2枚 | 2枚 |
| 5 | くりかえしで あつめよう | 反復を使って短いプログラムにする | 3枚 | 3枚 |

ステージ4以降はカード枚数に上限を設け、繰り返しを使わないとクリアできないようにする。各ステージには、開始時の説明文とヒント文を用意する。

### 高学年モード(全10ステージ)

高学年モードは、最初から繰り返しが使える状態で始まり、ステージ6〜8で「もし〜なら」(条件分岐)を学ぶ。ステージ6〜8には、実行のたびにどちらか一方がランダムにふさがる「?」マスがある。

| ステージ | 名前 | 学ぶこと | カード上限 | 星3つの条件 |
| --- | --- | --- | --- | --- |
| 1 | まがって すすもう | 繰り返しを使って曲がる | なし | 3枚以内 |
| 2 | ぜんぶ あつめよう | 繰り返しを使って複数の目標を回る | なし | 3枚以内 |
| 3 | くりかえしの まほう | 反復 | 2枚 | 2枚 |
| 4 | くりかえしで あつめよう | 反復で短くする | 3枚 | 3枚 |
| 5 | うずまき めいろ | 反復を5回組み合わせる | 5枚 | 5枚 |
| 6 | もしもの まほう | 条件分岐の導入(「そうなら」と「ちがったら」) | 4枚 | 4枚 |
| 7 | どっちの みち? | 条件分岐で道を選び、「ちがったら なし」を使う | 4枚 | 4枚 |
| 8 | もしの マスター | 「そうなら」「ちがったら」で回数の違う動きをする | 4枚 | 4枚 |
| 9 | かいだん | 「🔁 くりかえし」で→↓のまとまりを4回繰り返す | 4枚(🔁の中のカードも数える) | 4枚 |
| 10 | ゴールまで くりかえせ | 「🔁 🚩まで」と「もし」を組み合わせ、一つのルールでゴールまで進む | 2枚 | 2枚 |

### 地域へん(あかれんがパーク・あらしやま・きよみずでら・いね・あまのはしだて)の専用ステージ

舞鶴赤れんがパークを題材にした専用の盤面(横6マス×縦5マス。ほかの世界と同じ大きさ)を用意する。れんが倉庫と舞鶴湾の海は通れず、ゴールは港めぐり遊覧船ののりば。スタンプには番号があり、①→②→③の順に押さないとその場で失敗になる(「順次」を意識させるため)。

4つの地域へんは、共通の「地域の基本盤面」(低学年5・高学年10)をもとに、盤面を反転して使う。あかれんがパークはそのまま、あらしやまは左右反転、きよみずでらは上下反転、いね・あまのはしだては上下左右を反転する。答えも反転に合わせて自動で作り、ヒントは答えの前半だけを示す(あかれんがパークの1〜7は専用の文章)。

| ステージ | 名前 | 内容 | 低学年(星3つ) | 高学年(星3つ) |
| --- | --- | --- | --- | --- |
| 1 | まっすぐ すすもう | まっすぐゴールへ | 5枚 | 1枚 |
| 2 | よけて すすもう | 壁(倉庫・竹林・石垣・舟屋)をよけて曲がる | 8枚 | 4枚 |
| 3 | スタンプラリー | ①→②の順に集める(近い②を先に踏むと失敗) | 8枚 | 5枚 |
| 4 | ぐるっと まわろう | 反復(上限3枚) | 3枚 | 3枚 |
| 5 | くりかえしで あつめよう | 反復+順番(上限3枚) | 3枚 | 3枚 |
| 6 | 3つ あつめよう | ①→②→③を反復で回る(上限4枚) | — | 4枚 |
| 7 | どっちの みち? | どちらかの道がふさがる。「もし」で分岐(上限4枚) | — | 4枚 |
| 8 | もしの マスター | 「ちがったら」も使う分岐(上限4枚) | — | 4枚 |
| 9 | かいだん | 🔁でまとまりを繰り返す(上限4枚) | — | 4枚 |
| 10 | ゴールまで くりかえせ | 🔁🚩まで+もし(上限2枚) | — | 2枚 |

説明文には次の事実を入れる。倉庫は旧海軍が明治から大正にかけて建てたもの。8棟が国の重要文化財。1号棟は赤れんが博物館で、世界のれんがを展示している。出典: [グローバル・リンク・トラベル](https://www.gltjp.com/ja/directory/item/15320/)、[Walkerplus](https://www.walkerplus.com/spot/ar0726s573958/)、[舞鶴市 広報](https://www.city.maizuru.kyoto.jp/shisei/cmsfiles/contents/0000013/13282/2.pdf)、[嵐山・渡月橋(ANA)](https://www.ana.co.jp/travelandlife/article/002081/)、[清水寺(Walkerplus)](https://www.walkerplus.com/article/86339/)、[伊根の舟屋](https://www.gltjp.com/ja/directory/item/12067/)・[天橋立](https://www.gltjp.com/ja/directory/item/12123/)(グローバル・リンク・トラベル)。嵐山:渡月橋は桂川にかかる全長約155mの橋。清水寺:清水の舞台は高さ約13mでくぎを使わずに建てられている。伊根:舟屋は1階が船置き場で約230軒。天橋立:全長約3.6kmの砂州で日本三景のひとつ

## 3. 機能要件

### 3.1 プログラムの作成

| ID | 要件 |
| --- | --- |
| F-01 | 上・下・左・右の矢印カード4種をタップすると、プログラム欄の末尾に追加される |
| F-02 | 並べたカードには実行順の番号を表示する(🔁の中は「1-1」「1-2」) |
| F-03 | カードはドラッグで並べ替えられる(タブレットでは少し押し続けてから動かす)。外部ライブラリを使わずアプリ内で実装する |
| F-04 | カードごとの削除ボタン、「ひとつ けす」「ぜんぶ けす」を備える |
| F-05 | 繰り返しが使えるステージでは、カードの「×1」をタップするたびに回数が1〜9で増える |
| F-06 | カード上限のあるステージでは残り枚数を表示し、上限に達したら追加できなくする(🔁もその中のカードも1枚と数える) |
| F-07 | 高学年のステージ6〜8、10では「もし」カードを使える。「もし [方向] に すすめない なら」の方向、「そうなら」と「ちがったら」の動き(方向または「なし」)と回数を、タップで切り替える |
| F-08 | 「すすめない」とは、その方向のマスが障害物、ふさがった「?」マス、または盤面の外であることを指す |
| F-09 | 高学年のステージ9〜10では「🔁 くりかえし」カードを使える。置くと中にカードを入れる状態になり(黄色の枠)、続けてタップしたカードが中に入る。「✓ ここまで」で閉じ、「+ なかに いれる」で再び開く。中には矢印カードと「もし」カードを入れられる(🔁の入れ子は不可) |
| F-10 | 🔁の回数はタップで×2〜×9と「🚩まで」を切り替える。「🚩まで」はゴールに着いた瞬間に繰り返しをやめる |

### 3.2 実行と結果の表示

| ID | 要件 |
| --- | --- |
| F-11 | 「うごかす」でキャラクターが1マスずつ動き、実行中のカード(🔁の中のカードも)を強調表示する |
| F-12 | 実行中は「とめる」で中断できる |
| F-13 | 障害物や盤面の外にぶつかったら、何枚目のカードで起きたかをやさしい言葉で伝え、そのカードを揺らす |
| F-14 | ゴールに届かない、収集物が残っている場合は、それぞれに合った助言を表示する |
| F-15 | クリア時に星(2〜3個)と使ったカード枚数を表示し、「もういちど」「つぎへ」を選べる |
| F-16 | ヒントボタンで、ステージごとのヒント文を表示する |
| F-17 | 速さ(ゆっくり/はやい)と効果音のオン・オフを切り替えられる |
| F-18 | 「もし」カードの実行時は、条件の結果に応じて「そうなら」か「ちがったら」の行を光らせる |
| F-19 | 「?」マスのあるステージでは、ゴールしても、もう一方のマスがふさがった場合に失敗するプログラムはクリアにしない。その場合は「もし」カードを使うよう促す |
| F-20 | 「🔁 🚩まで」がゴールに着かず終わらない場合(動かないまま繰り返す、60回を超える)は止めて、「🔁 が ずっと おわらないよ」と伝える |

## 4. 非機能要件

| 区分 | 要件 |
| --- | --- |
| 動作環境 | 主要ブラウザ(Chrome、Safari、Edge)で動くこと。GIGAスクール端末(Chromebook、iPad、Windows)を想定する |
| 画面サイズ | 横幅860px以上は盤面と操作欄を横並び、それ未満は縦並びにする |
| 操作性 | タッチで押しやすいよう、カードボタンは76px四方以上とする |
| 表記 | 子ども向け画面はひらがな・カタカナ中心。漢字を使う場合はふりがなを付ける |
| アクセシビリティ | 情報を色だけで伝えない。OSの「視差効果を減らす」設定でも演出を止める |
| データ保存 | クリア記録・名前・表示設定はその端末のブラウザ内にのみ保存する。サーバーへの送信はしない |
| 個人情報 | 名前以外の個人情報は扱わない。名前は「つぎの ひとへ」で消せる |
| 外部依存 | 外部ライブラリは使わない(並べ替えとPDF作成はアプリ内で実装。QRコードは Kazuhiko Arase 氏の QRCode for JavaScript〈MITライセンス〉をページに内蔵)。Webフォント(Google Fonts)はオンライン時のみ使い、オフライン時は端末の文字(WindowsのBIZ UDPゴシック、iPadのヒラギノなど)、なければページに内蔵したNoto Sans CJK JPの一部(約230KB、SIL OFL)で表示する。ZIPのindex.htmlはインターネットなしですべての機能が動き、修了証の画像・PDFもそのまま保存できる |
| 著作権 | 29の世界とも「マイクラ風」の雰囲気にとどめ、既存ゲームの名称・ロゴ・キャラクターは使わない。ドット絵はすべてオリジナル |

## 5. 画面構成

画面は1ページで、上部のヘッダー、左の盤面、右の操作欄の3つに分かれる。結果や確認は画面中央のポップアップで表示する。ステージや世界を切り替えても盤面の位置が動かないよう、吹き出しは画面幅ごとの固定の高さ(幅861px以上は2行、640〜860pxは3行、520〜639pxは4行、それ未満は6〜7行。どのステージ・言語・目に優しいモードでも収まる行数にする)、盤面はすべての世界で6×5マスにそろえ、マスの大きさも共通にする。まめちしきは盤面の下に表示する。

| 領域 | 主な要素 |
| --- | --- |
| ヘッダー | タイトル、速さ・効果音ボタン、修了証ボタン(クリア後のみ)、きのう メニュー、「せかい」ボタン(今の世界を表示し、押すと世界えらびの画面を開く)、ステージ番号(獲得した星を表示) |
| 課題(上、横いっぱい) | ステージ名と学ぶことのチップ、せんせいモードのねらい、キャラクターの吹き出し(説明・ヒント・結果)、ばんの みかた |
| 盤面(左) | マスの番号、6×5マスの盤面(すべての世界で同じ大きさ)、まめちしき |
| 操作欄(右) | プログラム欄(並べたカードと残り枚数)、矢印カード4枚(高学年は「もし」も)、「うごかす」、ヒント・ひとつけす・ぜんぶけす。上端を盤面の上端にそろえる |
| あそびかた タブ | めいろ・ドットえ・データとAI・つくって あそぶ。めいろ以外は 課題・盤面・操作欄の代わりに 活動ごとの画面を出す |
| ポップアップ | クリア画面、修了証、記録消去の確認、せかい えらび、チュートリアルしゅう、あそびかた・べんきょうの しかた、せんせいモード、このアプリについて |

盤面は画面の幅と高さに合わせて大きさを決め、盤面全体がスクロールせずに見えるようにする(1366×768のChromebookでは、盤面と「うごかす」までが1画面に収まる)。幅860px以下では、課題→盤面→操作欄の順に縦に並べる。
