高専プロコン競技部門 体験（第35回「シン・よみがえれ世界遺産」・第36回「エ。ー縁結びの誘導についてー」・第37回「ヘキサうどん」）
バージョン 0.9.15（2026-11-11）

小学生・中学生が、全国高等専門学校プログラミングコンテスト 競技部門のルールを
iPad などの Web ブラウザだけで体験できる教材の試作版（モック）です。
公式の競技システムではありません。

------------------------------------------------------------
■ 使い方
------------------------------------------------------------
・app/procon_taiken.html を Safari / Chrome などで開きます。サーバーは不要です。
・iPad で使うときは、このファイルを「ファイル」アプリなどに入れて開くか、
  Web サーバーに置いてアクセスしてください。
・文字のフォント（M PLUS Rounded 1c、タイ語は Noto Sans Thai）だけインターネットから読みこみます。
  つながっていないときは、端末のフォントで表示されます。
・設定（色・ことば）、選んだ競技、作ったプログラムは、その端末のブラウザの中に保存されます。

------------------------------------------------------------
■ できること
------------------------------------------------------------
・競技の切り替え：第35回「シン・よみがえれ世界遺産」／第36回「エ。ー縁結びの誘導についてー」／第37回「ヘキサうどん」
・ルールを知る（スライド5枚）／ひとりであそぶ／ロボットとしょうぶ
・時間切れで模範回答を自動再生、対戦後はロボットの回答も再生
・プログラムでとく（ブロック型プログラミング。実行中のブロックが光る。第37回はお手本チームも同じマップを走る）
・勉強の仕方・遊び方（動画・競技ごとのコツ・「先生方へ」：学習指導要領との関連と授業の進め方）
・設定：画面の色（ふつう・ナイトモード・目にやさしい・色覚サポート）、
        ことば（日本語・English・Tiếng Việt・ไทย・Монгол）、リリースノート、このアプリについて

■ ソースを直すとき（src/）
------------------------------------------------------------
style.css     見た目（4種類の配色を含む）
body.html     画面の部品
i18n.js       日本語・英語・ベトナム語の文言（ここを直せば表示が変わります）
i18n_th.js    タイ語の文言

core.js       第36回のルール（園の回転）・ロボット・模範回答・盤面表示
kata_core.js  第35回のルール（型抜き）・抜き型・問題作成・模範回答・ロボット
kata_ui.js    第35回の画面（ルール説明・ゲーム・結果・再生）
hexa_core.js  第37回のルール（ヘキサうどん）・マップ作成・ロボット
hexa_ui.js    第37回の画面（ルール説明・計画・結果・再生）
i18n_hexa.js  第37回と「勉強の仕方・遊び方」の文言（5言語）
code.js       ブロック型プログラミング（3つの競技に対応）
app.js        画面の切り替え・設定・第36回のゲームと結果
assemble.py   上の部品を1つの HTML にまとめるスクリプト

直したあと、src フォルダで次を実行すると app/procon_taiken.html が作り直されます。
  python3 assemble.py
