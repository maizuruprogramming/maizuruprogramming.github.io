# 2026年11月 献立パース確認レポート

## 解析に適用したルール

1. 料理の先頭が `A` / `Ａ` の場合はA定食。先頭記号は料理名から除去する。
2. 料理の先頭が `B` / `Ｂ` の場合はB定食。先頭記号は料理名から除去する。
3. それ以外は共通料理とし、A/Bの両方に表示する。
4. `共通料理` は見出しであり、料理として登録しない。
5. B定食の料理の直下にある独立した `ごはん` / `ご飯` はB定食に含める。
6. `共通料理` 見出しの後にある `ごはん` / `ご飯` は共通料理に含める。
7. PDFのテキスト抽出でB料理とごはんが同じ行に連結された場合も、末尾の独立した「ごはん」を分離する。
8. アレルゲン赤丸表示は原本の画像確認ができた場合のみ確定する。今回のアレルゲン情報は未確認。
